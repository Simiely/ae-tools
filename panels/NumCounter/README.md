# NumCounter · 数字计数器面板

一个 After Effects 脚本面板 —— 填**起始 / 目标 / 帧数**,一键生成「数字递增到目标值」的动画。支持**步进、小数位、字距、对齐、等宽锁定、前缀/后缀、缓动**,并修复数字变化时**宽度跳动(抖动)**问题。动画由「数值」滑块关键帧驱动,生成后仍可拖滑块/关键帧调整,**无需重跑脚本**。

> 核心设计:**「数值」滑块关键帧 = 动画时间轴, sourceText 表达式 = 实时格式化**。改节奏拖滑块关键帧;改小数位/步进拖对应滑块即时变。

## 特性

- **起止与帧数**:起始数字、目标数字、总帧数(从当前时间指示器开始)。
- **步进值**:每次数字跳多少(如 0→100 步进 10 → 显示 0/10/20…/100);为 0 则连续递增。
- **小数位**(0~4):固定小数位数,如 `0.00` / `12.34`。
- **字距**(tracking):统一加宽控制,等宽字体下保持均匀。
- **字体 + 等宽锁定**:指定字体名;勾选「等宽锁定」强制 `Consolas` 等宽字体,**彻底消除数字宽度抖动**。
- **对齐**(左/中/右):数字增长只朝一个方向,配合等宽即稳定(推荐「中」或「右」)。
- **前缀/后缀**:如 `$` / `%` / `(` `)`,前后加固定字符。
- **缓动**(线性/缓入/缓出/缓入缓出):作用于「数值」滑块关键帧,控制增速节奏。
- **滑块可调**:生成的文本图层带「数值 / 步进 / 小数位」三个滑块效果,事后改即实时变。
- **单 Undo 组**:整次生成可整体撤销。

## 抖动根因与修复

**根因**:比例字体数字宽度不等("1" 比 "8" 窄),位数变化(99→100)或同位数内变化都让文本宽度变 → 左对齐整行右移、居中绕中心抖。

**修复(证据向,排版常识)**:
1. **等宽数字字体(最稳)**:选等宽字体(如 Consolas / Courier New),每位等宽零抖动。「等宽锁定」一键切。
2. **对齐**:右/居中让增长只朝一个方向,配合等宽即稳定。
3. **固定位数/前导零**:位数不变,但比例字体仍因 1/8 宽度差微抖 —— 前导零要**配合等宽字体**才彻底稳(本面板未内置前导零,原理同上,可在表达式改)。
4. **字距**:统一加宽;等宽下保持均匀,比例字体下按比例放大抖动(故建议配等宽)。

## 安装(免安装)

1. 部署(本仓库统一方式):
   ```
   python install.py            # 在 ae-tools 根目录运行,自动检测 AE 版本
   ```
   (或手动把 `NumCounter.jsx` 复制到 `%APPDATA%\Adobe\After Effects\<ver>\Scripts\ScriptUI Panels\`)
2. 重启 AE(脚本面板启动时扫描)。
3. 菜单「**窗口 › 扩展 › NumCounter · 数字计数器**」打开面板。

## 快速开始

1. 打开一个合成,把当前时间指示器放到动画开始帧。
2. 面板填:起始 `0`、目标 `100`、总帧数 `30`、步进 `1`、小数位 `0`。
3. 点「**生成**」——生成文本图层 + 「数值」滑块从 0 关键帧到 100,数字逐帧递增。
4. 预览:播放,数字从 0 走到 100。

## 常用操作

| 目标 | 操作 |
| --- | --- |
| 数字 0→100 递增 | 起始 0 / 目标 100 / 帧数 30 / 步进 1 / 生成 |
| 每 10 跳一次 | 步进填 10(0→100 → 0/10/20…/100) |
| 保留两位小数 | 小数位填 2(显示如 `12.34`) |
| 带单位 | 前缀填 `$`、后缀填 `%`(显示 `$100%`) |
| 消除抖动 | 勾「等宽锁定」+ 对齐选「中」或「右」 |
| 改动画节奏(事后) | 选中文本图层,拖「数值」滑块关键帧 |
| 改小数位(事后) | 拖「小数位」滑块值,显示即时变 |
| 改步进(事后) | 拖「步进」滑块值,显示即时变 |
| 增速带缓动 | 缓动选「缓入缓出」再生成 |
| 还原默认 | 点「重置」 |
