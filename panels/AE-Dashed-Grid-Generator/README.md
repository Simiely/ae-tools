# AE 虚线网格生成器（共用交接边）

一个 After Effects 2026 的 ScriptUI 面板脚本，一键生成**共用交接边**的虚线网格框（2×2 / 3×3 / 任意 N×M）。

## 特性

- **共用交接边**：内部线是相邻格子共用的单线（外框 + N-1 横 + N-1 竖），没有双线
- **参数化**：行列数、总宽高、线宽、虚线长度、间隙全部可调
- **缩放保持**：缩放「网格组」变换时，线宽与虚线间距自动保持（物理方案，非等比缩放也有效）
- **面板内状态区**：成功/失败信息直接显示在面板底部，不弹窗打断
- **调试友好**：出错时弹出可复制详情的调试对话框，并自动写日志

## 安装

1. 将 `AE_dashed_grid_shared-edge.jsx` 复制到：
   ```
   %APPDATA%\Adobe\After Effects\26.0\Scripts\ScriptUI Panels\
   ```
2. 重启 After Effects 2026

## 快速开始

1. 菜单 **窗口 → 扩展 → 虚线网格生成器**
2. 打开一个合成（先双击合成激活它）
3. 填好参数（列/行/宽/高/线宽/虚线/间隙）
4. 点 **生成网格**
5. 缩放网格时：展开图层的「内容 → 网格组 → 变换」，缩放**组变换**，线宽自动保持
