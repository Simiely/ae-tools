# 更新日志（CHANGELOG）

## v1.0.1（2026-09-21）—— 补断言测试(53 条) + 结构规整

- 此前【零测试】(291 行)。新增 `test_AudioScale.js`, **53 条断言**:
  三个表达式生成器(逐行比对生成的表达式文本) / Both Channels 索引探测(mock 4 种)
  + 源码级体检(版本号 / VER 位置 / 闸门位置 / Undo 组)。
- ⭐ 本面板特别值得测**表达式文本**: 三个 `build*Expr` 产出的是**写进 AE 表达式的字符串**,
  写错只会在 AE 的表达式错误提示里暴露, 从脚本侧看不见, 排查一次很贵。
- **结构规整**: `VER` 从 `buildUI` 内部**提到 IIFE 顶层** ——
  否则测试导出闸门引用不到它, 而且单一真相不该藏在某个函数里;
  顺带修上一版遗留的注释缩进(4 → 8 空格, 与代码行对齐)。
- 记录两条**契约**(不是 bug): ① `findBothChannelsEffectIndex` 不做 ampLayer 空值兜底
  (调用方 `getSelectedAudioLayer` 已保证非空); ② 图层名原样直插、不做转义,
  含双引号会破坏生成的表达式。
- 反向对照: 注入 3 处 → **3 条变红**, 还原即恢复。
