# 山峰频谱 MountainSpectrum

一键在合成里画出**等距横向排开的矩形阵列**，再用可拖动的控制点决定每根柱子的高度 ——
矩形离控制点越近就越高、宽度不变，于是连成一片中间高两侧低的山丘；
控制点加到足够多，就成了音频波谱的样子。

面板 **v0.9.0** · 适用 AE 2015.3+ 至 2026（ExtendScript / ScriptUI）

## 安装

在仓库根目录跑 `python install.py`（自动检测 AE 版本、补 UTF-8 BOM、逐字节校验），
或把 `MountainSpectrum.jsx` 直接放进：

```
.../Adobe/After Effects/<版本>/Scripts/ScriptUI Panels/
```

**必须重启 AE**（ScriptUI Panels 只在启动时扫描一次）→ 菜单 `窗口 > 扩展 > MountainSpectrum`

## 产物结构

一次「生成 / 重建」在当前合成里建出下列图层，全部包在**同一个 Undo 组**里（Ctrl+Z 可整体撤销）：

| 图层 | 数量 | 作用 |
|---|---|---|
| 形状图层 `山峰 柱` | 1 | N 个矩形组。**它的位置 = 行中心 X / 基线 Y** —— 拖它移动整行 |
| 空对象 `山峰 控制` | 1 | 7 个滑块：矩形宽 / 间距 / 基础高度 / 叠加方式 / 起伏曲线 / 影响范围倍率% / 边缘高度% |
| 空对象 `山峰点 k` | M | 每个波峰的**峰**，带 3 个滑块「影响范围」「高度」「边缘控制」 |
| 空对象 `山峰点 k 左` · `山峰点 k 右` | 2M | 每个波峰的**左右边缘控制点** —— 拖它们的 X 定山丘左右边界 |
| 空对象 `山峰 高度` | 1 | **总闸**：它离基线多高，整排最高柱就多高 |

> **一个波峰 = 一组 3 个可拖对象**：峰 + 左边缘 + 右边缘；M 个波峰 = M 组。

高度 / 位置 / 半径全部走**表达式**、不烘焙关键帧 —— 生成后拖任何东西都**实时生效**，不用重跑脚本。

## 三个核心操作

### 1. 拖「山峰点 k」= 移动一个峰

X 决定峰在哪，Y 决定峰多高（基线以上）。拖它，山丘实时跟着走。

### 2. 拖「山峰点 k 左 / 右」= 改**这一侧**的宽度

左右**互相独立**，可以一边缓一边陡（音频里的 attack / decay 不同）。

- 拖哪一侧就只改哪一侧
- **删掉某一侧** = 那一侧回退成「影响范围」的对称宽度；两侧都删 = 完全对称
- 拖到峰的**另一侧** = 该侧半径为负 → 钳到 0，等于**关掉这一侧**

### 3. 拖「山峰 高度」= 整排一起长高

它离基线多高，整排**最高那根**就多高，其余各峰按同一比例缩放 —— **形状不变**。

- 拖到基线 = 整排压平到基础高度
- **删掉这一层** = 关闭总闸，回到各点位独立高度（完全向后兼容）

## 参数速查：改完是否立即生效

| 参数 | 位置 | 立即生效 |
|---|---|---|
| 矩形宽 / 间距 | 控制器 | ✅ |
| 起伏曲线 / 叠加方式 | 控制器 | ✅ |
| 影响范围倍率% | 控制器 | ✅（可打关键帧让山丘一起"呼吸"） |
| 边缘高度% | 控制器 + 面板 | ✅ |
| 基础高度 | 控制器 + 面板 | ✅ |
| 影响范围 / 高度 / 边缘控制 | `山峰点 k` 效果控件 + 面板 | ✅ |
| 左右边界 | `山峰点 k 左/右` 的**位置属性** | ✅ |
| 最高高度 | `山峰 高度` 的**位置属性** | ✅ |
| 数量 / 点数 / 自动铺满 | 面板 | ❌ **需重新生成** |

## 参数含义

### 影响范围 —— 总共影响几根

点位滑块的值 = **总共影响几根竖条**（不是"每侧几根"）。

半径用 **kNN**：取"第 m 近那根柱子"的实际距离，所以填 9 就**恰好 9 根**。
唯一退化：行根数为偶数且点位恰落在两根正中时，会得到 m+1 根（对称窗口无法二选一，是几何事实）。

### 高度 —— px，基线以上

该点的峰高绝对值。**0 = 自动**（跟随点位的 Y 位置）。

> ⚠️ 总闸「山峰 高度」启用时，各点位的「高度」**退化为相对权重** —— 它不再表示绝对的像素高度，
> 而是"这个峰相对其他峰高多少"。想让某根固定成绝对高度，就把它调成最高的那根，再拖总闸到目标值。

### 边缘高度% —— 窗口最边缘那根保留多少「可用高度」

```
柱高 = 基础高度 + (峰高 − 基础高度) × 衰减
```

衰减作用在**地板之上**的区间，所以只要这个值 > 0，窗口内**每一根都保证高于基础高度**（都看得见）。

| 值 | 效果 |
|---|---|
| 100% | 窗口内全平（矩形窗，根数最准、边缘硬切） |
| **10%（默认）** | 边缘比地板高一截，山形柔和 |
| 0% | 边缘恰落在地板上（看不见），但**范围边界无台阶** |

> ⚠️ **范围边界有一道台阶**：范围内最低 = 地板 + 可用高度×e，范围外 = 地板，
> 两者相差 可用高度×e。这是"圈定范围"的固有代价，**台阶大小就是这个参数**，调小即变轻。

### 起伏曲线 / 叠加方式

- 曲线：余弦（默认）/ 高斯 / 线性 / 二次
- 叠加方式：
  - **叠加（求和）** —— 多峰重叠处会**超过**总闸高度（两峰相加）
  - **取最高** —— 重叠处恰好等于最高那个峰

## 预设

面板「预设管理」区：**4 个固定槽位 + 导出 / 导入配置**。

- 存在**工程所在目录**的 `MountainSpectrum.presets.json`（跟随工程走）
- **存储前必须先保存工程**（Ctrl+S），否则状态栏会提示
- 「使用」只回填面板，**不自动生成**（避免误毁当前合成）
- 导入**只覆盖非空槽位**（空槽不冲掉你现有的值）
- 存的字段：数量 / 自动铺满 / 矩形宽 / 间距 / 基础高度 / 基线% / 起伏曲线 / 叠加方式 / 影响范围 / 点数 / 点位高度 / 边缘高度%

## 常见问题

**Q：生成后一片空白？**
检查时间轴里有没有 `山峰 柱` 图层。若图层在但看不到柱子，多半是「基础高度」已经超过峰高。

**Q：拖「山峰点 k 左/右」没反应？**
表达式是**生成时烘进工程**的 —— 旧工程或改过脚本版本，需要点一次「生成 / 重建」。

**Q：范围边界有一道明显的台阶？**
把「边缘高度%」调小。调到 0% 完全没台阶，但边缘也会落回地板（看不见）。

**Q：改「数量」之后形状变了？**
「数量」是生成时写死的，必须重新生成；其余参数都是实时。

**Q：想整块搬走图样、峰形不变？**
把 `山峰 柱` **和所有 `山峰点`（含左右边缘点）一起选中**再拖。只拖 `山峰 柱` 的话，
点位是世界坐标、行从它们下面滑过，峰形会跟着变。
