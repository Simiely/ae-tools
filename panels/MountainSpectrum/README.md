# 山峰频谱 MountainSpectrum

一键在当前合成里画出**等距横向排开的矩形**，用若干**可拖动的波峰控制点**控制高度 ——
矩形离点越近越高、宽度不变，连成一片中间高两侧低的小山丘；波峰加够了就是音频波谱的样子。

矩形的高度/位置由**表达式**驱动（不烘焙关键帧），所以生成之后**拖点、拖滑块都实时生效**，不用重跑脚本。

- 面板版本：**v1.5.8**
- 安装位置：`%APPDATA%\Adobe\After Effects\<版本>\Scripts\ScriptUI Panels\`
- 菜单入口：`窗口 › 扩展 › MountainSpectrum`
- 源码：`panels/MountainSpectrum/MountainSpectrum.jsx`（单文件，免安装）

## 生成出来的东西

| 图层 | 内容 | 用途 |
|---|---|---|
| **形状图层「山峰 柱」** | N 个「柱 k」组（每组 = 矩形路径 + 组内填充）+ 图层级颜色控件 | 整排矩形。**拖这个图层 = 平移整行**（形状不变 —— 山形只由控制点决定）。 |
| **空对象「山峰 控制器」** | 10 个滑块：矩形宽 / 间距 / 基础高度 / 叠加方式 / 起伏曲线 / 边缘高度% / 节奏条开关 / 节奏间隔 / 节奏条高度% / 边缘过渡根 | 全局观感（这些也可以在面板上改，见下） |
| **波峰「山峰点 1【峰】..M【峰】」** | 每个带 1 个滑块「高度」 | **拖它 = 峰移动**（X 决定峰在哪、Y 决定峰多高） |
| **「山峰点 k【左缘】/ k【右缘】」** | 左右边缘控制点 | **拖它 = 改这一侧的宽度**（左右独立，可不对称） |
| **空对象「山峰 总高度闸」** | 总闸 | **拖它 = 整排最高柱变高/变矮**，其余各峰等比缩放（形状不变） |

> 一个波峰 = **一组 3 个可拖对象**（峰 + 左边缘 + 右边缘）。M 个波峰 = M 组。

## 三条最重要的操作

### 1. 改宽度 → 拖「山峰点 k【左缘】/ k【右缘】」

```
左半径 = 峰X − 左边缘点X          右半径 = 右边缘点X − 峰X
```

- **拖哪个改哪一侧** → 天然的 attack/decay 不对称（左边缓右边陡，或反过来）
- **删掉某一侧** → 那一侧退回**自动宽度**（由 数量/矩形宽/间距/点数 推算）
- **把边缘点拖到峰的另一侧** → 该侧半径变负 → 钳到 0 = **关掉这一侧**
- 面板上的 **「均分边缘点」** = 按自动宽度一键摆齐所有波峰的左右边界

### 2. 改高度 → 拖「山峰点 k【峰】」（或拖总闸）

- 拖「山峰点 k【峰】」的 **Y** = 这个峰的绝对高度（峰高 = 基线 − 点位Y）
- 想让某个峰用**数字**指定高度 → 面板「点位高度」或该点位的「高度」滑块（0 = 自动跟随 Y）
- **拖「山峰 总高度闸」空对象** = 整排最高柱的高度；其余各峰**等比缩放、形状不变**
  - 拖到基线 = 整排压平
  - **删掉这一层 = 关闭总闸**，回到各点位自己的高度

### 3. 节奏条 → 面板「节奏」分组（v1.1.0）

勾选「节奏条开关」复选框后，每隔「节奏间隔」根竖线有一根更高的竖线（从最左第 1 根开始数），
「节奏条高度%」决定它独自有多高（= 基础高度 × 该值，默认 180%）。

- **山外**：节奏条 = 基础高度 × 高度%，独自高
- **进入山丘（v1.3.2）**：只要在任一点位的影响窗口内，节奏条就**完全跟随山丘轮廓**（与邻居同高、零戳出）；
  只有完全在山外才恢复独自高（基础高度 × 高度%）
- **离开山丘**：自动恢复独自高度
- **开关关**：与 v1.0.0 行为逐点一致

四个参数都在面板「节奏」分组，改完立即生效，也可随预设一起存。
「边缘过渡(根)」（v1.5.0，默认 3）：边缘点从"一个点"扩展为"点 + 羽化带"，带内所有柱高度线性过渡 —— 山脚与节奏条进出场都平滑，静态/动画都生效；0 = 硬边界。

### 3. 改形状 → 「基础高度」与「边缘高度%」

- **基础高度** = 山丘之外所有矩形的平坦高度（**加法基线**：柱高 = 基础高度 + 超出量）
- **边缘高度%** = 窗口最边缘那根保留【地板之上可用高度】的百分比
  - `100%` = 窗口内全平（矩形窗，边缘硬切）
  - `0%` = 边缘渐隐到零（山形最柔，但边缘看不见）
  - 默认 `10%` 兼顾

## 面板参数：哪些改完立即生效，哪些需要重新生成

| 改完**立即生效** | 矩形宽 / 间距 / 基础高度 / 基线(%合成高) / 起伏曲线 / 叠加方式 / 点位高度 / 边缘高度% / 节奏条开关 / 节奏间隔 / 节奏条高度% |
|---|---|
| **需要重新生成**（结构性参数） | 数量 / 自动铺满 / 点数 |

结构性参数改完**会明确提示**（不再静默）。这三项改变的是图层/矩形组/控制点的数量，必须重建。

> 面板上不需要点「生成」也能调的，就是上表第一行那 8 个。它们会被直接写进控制器的同名滑块、
> 推给所有点位、或移动形状图层 —— 表达式每帧读这些值，所以立刻生效。

## 面板按钮

| 按钮 | 作用 |
|---|---|
| **生成 / 重建** | 按面板参数重建全部图层（会先清理旧的）。**改「数量 / 自动铺满 / 点数」后必点** |
| **诊断** | 把 AE 版本 / 工程 / 图层 / 滑块值写入底部「调试输出」区；配合「复制」按钮一键反馈 |
| **重设点位** | 只增删波峰、按新点数重新均分 X、摆齐边缘点；**保留你调好的高度** |
| **均分边缘点** | 按自动宽度摆齐所有波峰的左右边界（替代旧版"填数字设宽度"） |
| **随机波峰** | 把各波峰高度随机化（位置不动），一键出波谱感 |
| **清理** | 删除本插件生成的所有图层（含边缘点与高度控制点） |
| 预设：存储 1-4 / 使用 1-4 / 清除全部 / 复位 / 导出配置 / 导入配置 | 见下 |

**全部操作都在同一个 Undo 组里，一次 Ctrl+Z 可整体撤销。**

## 预设槽（4 固定槽位）

```
存储 [1][2][3][4] [清除全部]
使用 [1][2][3][4] [复位]
[导出配置] [导入配置]
```

- 预设文件存在**工程所在目录**：`MountainSpectrum.presets.json`（跟随工程走，不用 `app.settings`）
- 存了哪些字段：参数表里的全部 14 个参数（数量 / 自动铺满 / 矩形宽 / 间距 / 基础高度 / 基线% / 起伏曲线 / 叠加方式 / 点数 / 点位高度 / 边缘高度% / 节奏条开关 / 节奏间隔 / 节奏条高度%）
- **不存**点位的实际位置与边缘点的实际位置 —— 那是工程数据，不是面板参数
- ⚠️ **存储前先保存工程（Ctrl+S）**，否则预设文件没有落点，会状态栏提示
- 「使用」只回填面板，**不自动生成**（避免误毁当前合成）；回填后点「生成 / 重建」生效
- ⚠️ 老预设文件（v1~v3）可以直接读：里面的 `r` 字段（旧「影响范围」）会被忽略，其余字段照常生效

### Q：想让整座山跟随某个图层运动（设父级），怎么做？

给 **「山峰 柱」设父级** 即可（v1.5.8 起正确支持）。原理是：**控制点是固定在合成里的地形**，
柱的高度按它在**合成空间的真实位置**（`toComp`）对地形采样 —— 父级带着柱走，走到哪儿就按哪儿的地形起伏：

- 父级带着柱**经过**控制点附近 → 按该处地形起伏（扫过地形的动态效果）
- 柱被带**离**控制点影响范围 → 回到基础高度（不再起伏）

| 图层 | 能设父级吗 | 为什么 |
|---|---|---|
| 山峰 柱 | ✅ 可以 | 它是采样者，位置就是采样点，跟随运动正是要的效果 |
| 山峰 控制器 | ❌ 不要 | 地形层 —— 设了父级地形跟着动，起伏就乱了 |
| 山峰 总高度闸 | ❌ 不要 | 地形层（最高柱的基准） |
| 山峰点（峰/左缘/右缘） | ❌ 不要 | 地形本身 —— 设了父级地形变形 |

- 面板「诊断」按钮会报告各层**父级状态**，地形层被设了父级会标 `<-- !! 基准层不该有父级`
- ⚠️ 父级带**旋转/缩放**时表现未验证（位移型父级最稳）
- ⚠️ 已有工程需**重新生成一次**才会用上新表达式（表达式是生成时写进图层的）
- 历史：v1.5.7 曾把基准挂到「控制器」上（山形被钉死、不随位置采样）—— 该方向已被 v1.5.8 取代

## 常见问题

**Q：拖了没反应？**
先确认改的是哪一类参数（见上表）。若改的是「数量 / 自动铺满 / 点数」，需要点「生成 / 重建」。

**Q：山丘的"脚"被地板吃掉了，边缘几根看不见？**
把「边缘高度%」调大一点，或把「基础高度」调小。

**Q：想让整座山长高，但形状不变？**
拖「山峰 总高度闸」空对象。**不要**去改各点位高度（那会改形状）。

**Q：总闸拖到基线了，整排都平了？**
把「山峰 总高度闸」往上拖回去；或者删掉这一层 = 关闭总闸。

**Q：面板宽度会不会自己变？**
不会。输入框与状态栏的宽度在建控件时钉死了（`preferredSize` / `minimumSize` / `maximumSize` 三处），
内容变长只在框内滚动或换行。
