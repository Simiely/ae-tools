## [1.1.0] - 2026-08-12

### 新增

- 水体/高光颜色与透明度控制：HSL 调色板对话框（H/S/L 滑块 + 预览，参考 starry-sky-generator）+ HEX 直接输色（# 前缀外置）
- 循环帧数参数（帧为单位，0=自动按上涨速度计算循环时长）
- 生成后颜色由 **Color Control 控件**驱动（AE 原生取色器，值含 RGBA，一个参数控制颜色）
- 点击色块直接打开调色板（不再需要「…」按钮）

### 变更

- 颜色区一行布局：色块 + HEX + 透明度
- 移除吸色功能（sampleImage 在 ExtendScript 不稳定）
- 移除 RGB 三滑块 / HSL 色相滑块方案，颜色统一改用 Color Control

### 修复

- sampleImage 用错对象（AVLayer 无此方法，应为 AVItem/CompItem）——吸色功能移除
- ScriptUI graphics.newBrush 颜色值应为 0-1（原误用 0-255）

## [1.0.0] - 2026-08-12

### 新增（首发，聚合 v1-v17 全部能力）

- 一键生成「水面上涨波动」合成：背景 + 水体（闭合多边形路径 + 纯色填充）+ 波峰高光线（描边），波浪自动上涨 → 到顶回底循环
- 波浪参数：上涨速度 / 流动速度 / 波峰高度 / 波长
- 噪波控制：噪波开关（Perlin 噪波）+ 种子 + 噪波速度 + 噪波幅度 + 噪波颗粒（最小 4）
- 4 槽位预设：存储 1-4 / 使用 1-4 / 清除全部 / 复位；双层持久化（工程 JSON `水面波动预设.json` + app.settings 全局保底）
- 参数复位；报错弹窗（可复制）；UI 显示参数最小范围（文字化）

### 修复

- 集合变更后引用失效导致的"对象无效"（现取现用 findGroupByName/findPathProp）
- 形状图层错位（图层 + 形状组变换归零，match name 跨语言）
- AE 崩溃（路径闭合到底部 + 保守表达式语法）
- 渐变填充 match name 兼容问题（改用纯色）

### 变更

- 早期「波浪层数」参数移除，替换为噪波体系
- 预设由命名式改为 4 槽位（对齐 AE-Lyrics-Animator）
- 早期「水位回底」按钮移除，替换为「复位参数」
