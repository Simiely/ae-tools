# AE-Water-Rise-Generator · 水面波动生成器

AE 2026 水面波动生成器（ScriptUI Panel）——一键生成「水面上涨波动」效果合成：波浪持续上涨、到顶自动回底循环，支持噪波随机起伏与 4 槽位预设。

## 功能

- **一键生成**：设置参数 → 点「生成水面效果」，自动创建合成 + 背景 + 水面（蓝色水体 + 波峰高光线），波浪表达式驱动，到顶回底自动循环
- **波浪参数**：上涨速度、流动速度、波峰高度、波长
- **循环控制**：循环帧数（帧，0=自动按上涨速度）
- **噪波控制**（解决波浪过于均匀）：噪波开关 + 种子 + 噪波速度 + 噪波幅度 + 噪波颗粒
- **颜色控制**：水体/高光颜色与透明度——HSL 调色板 + HEX 直接输色
- **参数均可后期调节**：生成时数值参数以滑块、颜色以 **Color Control**（AE 原生取色器）挂在水面图层上，AE 内可直接调
- **4 槽位预设**（对齐 AE-Lyrics-Animator）：存储 1-4 / 使用 1-4 / 清除全部 / 复位；双层持久化（工程 JSON + app.settings 全局保底）
- **运行诊断**：报错弹窗显示错误与已执行步骤（可全选复制）

## 安装

1. 将 `WaterRisePanel.jsx` 复制到 AE 的 ScriptUI Panels 目录：
   - **Windows**: `C:\Program Files\Adobe\Adobe After Effects 2026\Support Files\Scripts\ScriptUI Panels\`（或用户级 `%APPDATA%\Adobe\After Effects\26.0\Scripts\ScriptUI Panels\`）
   - **macOS**: `/Applications/Adobe After Effects 2026/Scripts/ScriptUI Panels/`
2. 重启 AE，通过 **窗口 > 扩展 > WaterRisePanel** 打开面板
3. 在 **编辑 → 首选项 → 脚本和表达式** 开启 **「允许脚本写入文件和访问网络」**（预设持久化需要）

## 快速开始

1. 打开或新建一个 AE 工程（**先保存 .aep**，预设才能跟工程走）
2. 面板设置参数（默认值即可出效果）
3. 点 **生成水面效果** —— 自动创建「水面上涨」合成并打开
4. 在合成中预览：波浪自动上涨 → 到顶回底循环

### 噪波示例

- 想模拟自然水面 → 开「噪波开关」，种子换几个值对比
- 波纹更细碎 → 噪波颗粒调小（最小 4）
- 波纹起伏更明显 → 噪波幅度调大
- 波纹动得更快 → 噪波速度调大

## 参数一览

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| 宽度 / 高度 | 400×600 | 最小 64 | 合成尺寸 (px) |
| 时长 | 0（自动） | — | 秒；0 = 按循环周期自动算 |
| 循环帧数 | 0（自动） | — | 帧；指定多少帧完成一次"底→顶"循环，0 = 按上涨速度自动 |
| 上涨速度 | 90 | 最小 1 | px/秒，越大涨得越快 |
| 流动速度 | 2.4 | — | 波浪横向流动速度 |
| 波峰高度 | 12 | 最小 1 | 正弦波振幅 (px) |
| 波长 | 180 | 最小 20 | 正弦波波长 (px) |
| 噪波开关 | 关 | — | 启用 Perlin 噪波随机起伏 |
| 种子 | 1 | 最小 0 | 噪波随机波形（同种子可复现） |
| 噪波速度 | 0.9 | 最小 0 | 噪波随时间演化的速度 |
| 噪波幅度 | 0.6 | 最小 0 | 噪波起伏大小（波峰高度的比例） |
| 噪波颗粒 | 90 | 最小 4 | 噪波空间频率（px，越小越密） |
| 水体颜色 | #458ED | — | 水体填充色（点色块弹 HSL 调色板，或直接输 HEX） |
| 水体透明度 | 100 | 0-100 | 水体不透明度 % |
| 高光颜色 | #FFFFFF | — | 波峰高光线颜色 |
| 高光透明度 | 20 | 0-100 | 高光线不透明度 % |

> 生成后所有参数（含颜色）都以效果控件挂在「水面」图层上：数值用滑块，颜色用 **Color Control**（AE 原生取色器，点色块弹取色器直接调 RGBA）。

## 预设管理

- **存储 1-4**：把当前参数保存到对应槽位
- **使用 1-4**：回填对应槽位参数到面板（无数据时按钮置灰）
- **清除全部**：清空两处存储
- **复位**：面板参数恢复默认值
- 存储位置：`.aep` 工程同级目录 `水面波动预设.json`（跟工程走）+ app.settings 全局保底；读取优先工程 JSON
