# QuickKey · 节点式 K 帧排程面板

一个 After Effects 2015.3+ 脚本面板 —— 以**当前时间指示器为锚点**,用 5 个节点位排布关键帧时间,一键给选中的任意属性批量打关键帧。快速 K 动画、错峰序列、循环节奏,一次点击完成。

> 核心设计:**时间排程(何时打帧)由节点面板决定,打帧目标(打在哪)由你在时间轴里选中什么决定** —— 位置/缩放/旋转/不透明度/任意效果参数都通用。

## 特性

- **N 节点位排程(默认 5,可 1~30)**:顶部「节点数」输入框填几就显示几行,三种模式锚点规则自动适配
  - 起始:锚点排第 1 位,下方 N-1 节点
  - 中间:锚点排第 ⌈N/2⌉ 位,上方 ⌈N/2⌉-1、下方 N-⌈N/2⌉(偶数时略偏上)
  - 末尾:锚点排第 N 位,上方 N-1 节点
- **节点可开关**:关闭的节点从排程中**完全剔除**——不打帧、不占位,后续节点按最近开启节点重算间隔
- **间隔以帧为单位**:每个节点的数字 = 与"靠锚点一侧**最近开启节点(或锚点)**"的帧距
  - 锚点下方:从锚点往后累加(+5 → +10 → +15 …)
  - 锚点上方:从锚点往前倒推(−5 → −10 → −15 …)
- **数值输入类型可切换**(下拉:1 个空 / 2 个空 / 3 个空 / 公式)
  - 1 个空:单值;2 个空:二维数组(位置/缩放/锚点);3 个空:三维(3D 图层)
  - **表达式模式**:单个表达式框,点按钮把表达式写入选中属性(不排关键帧),如 `wiggle(5, 50)`
  - 切换类型保留已填文本(单值 `50` 切 2 空 → X=50、Y 空);留空 = 用属性当前值
- **每节点数值输入**:每空一格直填(1 空=单值,2 空=[X,Y],3 空=[X,Y,Z]);**留空 = 用属性当前值**
- **数值位数预检**:执行前校验输入位数与属性维度(1/2/3)是否一致,不匹配 → 直接提示「数值位数不匹配」并中止,不做任何写入(留空用当前值的节点不参与校验)
- **曲线功能(v0.2.0)**:勾选「曲线功能」后,每两个**开启的相邻节点**之间 = 一段曲线(5 节点全开 = 4 段;关闭节点断开链条,段随开关自动重排)
  - 每段:预设下拉(自定义 + 内置 4 个 + 导入的)+ **x1 y1 x2 y2 四个输入**(cubic-bezier)
  - **选预设 → 四个空自动填入对应数值**;手填数字 → 数值恰好等于某预设时下拉显示该预设名,否则显示「自定义」
  - 内置预设:线性 `0 0 1 1` / 缓入 `0.42 0 1 1` / 缓出 `0 0 0.58 1` / 缓入缓出 `0.42 0 0.58 1`
  - **导出/导入预设**:「导出预设」把当前全部预设(内置 + 已导入)存成 JSON(默认当前 AE 工程目录,UTF-8);编辑该文件后「导入预设」合并进列表(同名覆盖、新名追加),下拉立即可选
  - 打帧时自动套用曲线:bezier 近似转 AE 缓动(`setTemporalEaseAtKey`——**X 坐标→影响**(出=x1×100、入=[1−x2]×100)、**Y 坐标→速度**(y1×平均速度/x1 等),社区公认公式);线性段即 AE 默认线性
  - **端点平滑开关**:勾选后曲线首/末帧速度归零,两端水平圆润(类似 Easy Ease);不勾 = 硬端点(现状)
  - 表达式模式自动隐藏曲线区(表达式覆盖关键帧,曲线无意义)
- **全参数预设管理(v0.3.5)**:4 槽位(存储 1-4 / 使用 1-4 / 复位 / 清除全部)+ **导出配置 / 导入配置**(全量备份 = 当前参数 + 槽位 + 曲线库);双层持久化(工程目录 `quickkey_配置.json` 跟工程走 + AE 全局设置保底),打开面板自动恢复槽位
- **实时预览**:每个节点右侧实时显示相对当前时间指示器的帧偏移,改数字/开关/模式立即重算
- **任意属性通用**:打帧目标 = 时间轴里选中的属性(`selectedProperties`),不限于五大属性
- **一键撤销**:整次打帧在一个 Undo 组里,Ctrl+Z 整体回退
- **调试报告**:「调试」按钮弹出本次执行完整明细(每节点时间/数值/解析结果、每属性失败原因与错误信息、表达式启用状态);**打帧结果为零时自动弹出**,一眼定位"为什么没打上帧"
- 状态栏提示结果,不弹窗打扰;空选区/未激活合成有明确提示

## 安装(免安装)

1. 部署(本仓库统一方式):
   ```
   python install.py            # 在 ae-tools 根目录运行,自动检测 AE 版本
   ```
   (或手动把 `QuickKey.jsx` 复制到 `%APPDATA%\Adobe\After Effects\<ver>\Scripts\ScriptUI Panels\`)
2. 重启 AE(脚本面板启动时扫描)。
3. 菜单「**窗口 › 扩展 › QuickKey · 快速K帧**」打开面板。

## 可用曲线预设(仓库自带)

`预设/工程预设260819.json` —— 13 个可直接使用的曲线预设(导入即用):

| 分组 | 预设 |
|---|---|
| 内置 4 个中文 | 线性 / 缓入 / 缓出 / 缓入缓出(打开面板即有,无需导入) |
| Cubic 5 个 | Cubic-3 / Cubic-2 / Cubic-1 / Cubic-Out / Cubic-In |
| Quart 4 个 | Quart-In / Quart-Out / Quart-2 / Quart-3 |

用法:勾选「曲线功能」→ 点「**导入预设**」→ 选择该文件。
导入后与内置一样可下拉选择、数值匹配、打帧自动套用。

## 快速开始(依次落下动画)

1. 在合成里选中 5 个图层,按 **P** 展开位置,选中这 5 层的「位置」属性。
2. 当前时间指示器放在动画开始的那一帧,面板默认「起始帧」,间隔默认 5 帧。
3. 每个节点「数值」列填上该节点要落到的位置(如 `960, 540`;想沿用各层当前位置就留空)。
4. 点「**打帧**」——每个节点在对应时间(+0/+5/+10/+15/+20 帧)打上你填的数值。
5. 预览:按 Home 回到开头播放,图层依次跳到位。

> 想从中间向两边展开?当前时间指示器放中间,模式切「中间帧」,上方 2 节点 + 下方 2 节点,一层变两层动画。

## 常用操作

| 目标 | 操作 |
| --- | --- |
| 依次落下/弹出(向前序列) | 当前时间指示器=起点 → 模式=起始帧 → 设间隔 → 打帧 |
| 从中间向两边展开 | 当前时间指示器=中间 → 模式=中间帧 → 上下节点设间隔 → 打帧 |
| 收尾序列(先到齐再依次走) | 当前时间指示器=末尾 → 模式=末尾帧 → 上方节点设间隔 → 打帧 |
| 只打其中几个节点 | 关掉不需要的节点(关闭即从排程剔除,后续节点重算) |
| 增加/减少节点数 | 顶部「节点数」框填数字回车(1~30);缩容再扩容旧值保留 |
| 长序列动画(10+ 关键帧) | 节点数填 10+ → 设间隔 → 打帧 |
| 位置/缩放批量填 X/Y | 数值输入切「2 个空」→ 每节点填 X、Y 两框 → 打帧 |
| 3D 图层位置/缩放 | 数值输入切「3 个空」→ 每节点填 X、Y、Z |
| 给属性加表达式 | 数值输入切「表达式」→ 填表达式(如 `wiggle(5,50)`)→ 点「应用表达式」 |
| 给动画加缓动 | 勾「曲线功能」→ 每段选预设(或手填 x1 y1 x2 y2)→ 打帧自动套用 |
| 用自定义曲线 | 「导出预设」存 JSON → 编辑文件 → 「导入预设」→ 下拉选择 |
| 打帧没生效,看原因 | 点「调试」看报告;打帧结果为零会自动弹出报告 |
| 不透明度 100→0 闪烁 | 选「不透明度」属性 → 节点数值分别填 100 / 0 / 100 / 0 → 打帧 |
| 位置依次移动 | 数值列依次填 3 个坐标(如 `200` / `400` / `600`)→ 打帧 |
| 任意效果参数 | 展开效果 → 选中参数 → 填数值 → 打帧 |
