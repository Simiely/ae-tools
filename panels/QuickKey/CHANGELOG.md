# 更新日志(CHANGELOG)

## v0.1.18(2026-08-18)

- **维度判断补两个缺口**(盘点所有判断方式后):
  - 摄像机/灯光图层**恒 3D**(无 3D 开关):propLayerInfo 识别 layerType(camera/light),propDimOf 强制 3D
  - **分离尺寸跟随者**(位置X/位置Y)恒 1 维:separationLeader 非空即判 1
  - 回归测试扩至 **50 断言**

## v0.1.17(2026-08-18)

- **维度判断彻底修正(用户三次坚持无 3D,诊断实测定案)**:
  - 定案:AE 26.0 中 **2D 图层(3D开关=关)的位置/锚点 propertyValueType=6413(ThreeD_SPATIAL)、缩放=6414(ThreeD)**——`.value` 和 `propertyValueType` 都报 3D,唯一可靠维度真相 = 图层 `threeDLayer` 开关
  - 修复:propDimCore 纯决策——变换属性(位置/缩放/锚点/方向)以图层 3D 开关定维度;OneD 恒 1 维;非变换属性退回 propertyValueType(枚举数值硬编码,AE 26.0 实测)
  - 回归测试扩至 **48 断言**(含"2D 图层位置→2"用户场景)

## v0.1.16(2026-08-18)

- **图层诊断遍历修复**:propLayerInfo 改用 duck-typing(containingComp)识别 Layer + parentProperty/propertyGroup 双通道上溯 + 防死循环守卫(原 instanceof 遍历静默失败,图层标注不显示)
- 待用户跑定案脚本确认枚举是否碰撞(官方文档无数值,无法排除 TwoD_SPATIAL 与 ThreeD_SPATIAL 数值相同导致误判)

## v0.1.15(2026-08-18)

- **位数预检加入原始诊断**:不匹配提示附带 AE 原始数据——propertyValueType 常量名(如 ThreeD_SPATIAL)+ 图层名 + 所在合成 + threeDLayer 开关状态,下一份报告即可确认"AE 真报 3D"还是"图层开了 3D 开关"

## v0.1.14(2026-08-18)

- **执行层重构**(用户:逻辑越来越乱,先优化):
  - doKey 拆三段:**buildPlan(纯计算,node 可测)→ executePlan(只写 AE)→ buildReport(纯文本拼接)**,报告与执行不再交错
  - 抽公共辅助 `withUndo` / `perProp` / `failDimCheck`,消除 doKey 与 applyExpression 的重复
  - 新增纯函数 `buildPlan` / `planHasExplicit`,回归测试扩至 **39 断言**
  - 行为不变:报告格式、位数预检、自动弹窗、undo 分组全部保持
- 重构中发现并修复:计划里 value 归一化(null 而非 undefined)、raw 显示去尾部空逗号

## v0.1.13(2026-08-18)

- **位数预检重写**:拆成单一职责函数(propDimOf / propLayerInfo / dimCheck),逻辑理顺
- 提示新增图层诊断:3 维属性若所属图层开了 3D 图层开关,直接写明「(图层「X」已开启 3D 图层开关)」——"2D 图层却报 3 维"的真相一眼可见

## v0.1.12(2026-08-18)

- **修复 2D 图层被误判为 3 维**:维度判断改用 AE 权威 API `propertyValueType`(OneD/TwoD/TwoD_SPATIAL/ThreeD/ThreeD_SPATIAL)
  - 根因:旧判断用 `value.length`,而 AE 2026 中 2D 图层的位置/锚点 `.value` 返回 `[x,y,0]`(3 元素),导致 2D 误判 3 维、位数预检误报
  - COLOR/自定义/文本等属性不参与预检,执行时兜底

## v0.1.11(2026-08-18)

- **位数预检提示增强**:所有不匹配属性维度一致时,弹窗直接给出「建议「数值输入」切到「N 个空」」(如 3D 属性 × 2 空 → 建议切「3 个空」)

## v0.1.10(2026-08-18)

- **数值位数预检**(撤销 v0.1.8 自动广播/补齐,用户明确要求):执行前校验输入位数与属性维度,不匹配 → 弹窗「数值位数不匹配,未执行」并中止,不做任何写入
- 留空(用当前值)节点不参与校验;特殊属性不预检、执行时兜底
- 回归测试回到 **33 项断言**(移除 fillDimsValue 用例)

## v0.1.8(2026-08-18)

## v0.1.2(2026-08-18)

## v0.1.0(2026-08-18)— 初始版本

- **首个可用版本**:节点式 K 帧排程面板

  - 打帧目标 = `comp.selectedProperties`(任意属性通用),数值 = 属性当前值
  - 整次打帧在单个 Undo 组,Ctrl+Z 一键撤销
