# 更新日志(CHANGELOG)

## v0.1.4(2026-08-18)

- **节点数动态化(1~30,默认 5)**:顶部「节点数」输入框,填几就显示几行节点
  - 三种模式锚点规则自动适配 N:起始 = 第 1 位 / 中间 = 第 ⌈N/2⌉ 位 / 末尾 = 第 N 位
  - 行池复用(增删只切 visible 不重建控件),缩容再扩容旧槽位数值保留
  - 回归测试扩至 **29 项断言**(N=7/4/8/6 排程 + anchorPos 规则)

## v0.1.3(2026-08-18)

- **关闭节点语义变更:占位 → 完全剔除**——关闭的节点不打帧、不占位,
  时间链只沿最近开启节点传播(`computeTimes` 对关闭槽位返回 null)
- 新增 4 项"关闭剔除"回归用例,test_quickkey.js 扩至 **19 项断言**

## v0.1.2(2026-08-18)

- **修复「中间帧 / 末尾帧」时间计算 bug**:倒推循环误用锚点一侧邻居的间隔
  (`gap[i+1]`),改为节点自己的间隔 `t[i] = t[i+1] - gap[i]`;
  非均匀间隔下中间/末尾模式时间不再错位(默认全 5 时两种公式相同,故起始帧未暴露)
- **术语修正**:「播放头」→ AE 官方学名「当前时间指示器」(Current Time Indicator, CTI)
- 新增 **test_quickkey.js 回归测试(15 项断言)**,computeTimes 抽为纯函数可 node 直测

## v0.1.1(2026-08-18)

- **新增每节点「数值」输入列**(列头:开关 | 节点 | 间隔 | 数值 | 时间)
  - 打帧值 = 节点数值;支持逗号分隔多维(位置 `960, 540`、缩放 `100, 100`)
  - **留空 = 用属性当前值**,与 v0.1.0 行为兼容
  - 显式数值与属性维度不匹配时该键跳过,状态栏明确提示未生效数量
  - 锚点行同样可填数值

## v0.1.0(2026-08-18)— 初始版本

- **首个可用版本**:节点式 K 帧排程面板
  - 当前时间指示器 = 锚点帧,角色三选:起始 / 中间 / 末尾(锚点槽位 1/3/5)
  - 5 节点位,非锚点节点可开关(关闭 = 占位不打帧)+ 帧距数字
  - 间隔语义:与"靠锚点一侧相邻节点"的帧距(下方累加 / 上方倒推)
  - 每节点实时预览相对当前时间指示器的帧偏移
  - 打帧目标 = `comp.selectedProperties`(任意属性通用),数值 = 属性当前值
  - 整次打帧在单个 Undo 组,Ctrl+Z 一键撤销
  - 状态栏提示结果;未激活合成 / 未选中属性有明确提示
- 四件套文档建立(README / AGENTS / DEVELOPMENT / CHANGELOG)
- **尚未真机验证**,验证通过后转「稳定」并更新本文件
