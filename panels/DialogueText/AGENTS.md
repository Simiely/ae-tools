# AGENTS.md — 对话文本动画 DialogueText

## 本目录是什么

一个 **AE ScriptUI 面板**，由 `_template/` 派生，v0.11.11 实现：

选中时间轴上的**文本图层**（可多选）→ 就地读取 `Source Text` → 加**出现窗口蒙版 + 文本动画器**。
不新建图层、不改文字/字体/字号/图层位置；文字只在窗口内出现，窗口外不显示。
**窗口规则**：段落文本（框文本）= **你给的段落框**（宽高都不动）；
点文本 = 贴合文字的外框。四边边距（可正可负）、羽化距离、羽化强度（蒙版不透明度）都在面板输入。

两种方式：`横向滚动` / `逐字出现`（逐字出现 = 一整套：出现 + 满窗左移 + 滑出）。
面板上是**两个互斥单选**（不是多选、也没有下拉）：选中哪个就只显示并使用哪套参数 ——
`横向滚动参数`（方向 / 时长 / 开头曲线 / 结束曲线）或
`逐字出现参数`（渐隐 / 出现 / 隐藏 / 隐藏像素）；文本框参数两种方式共用。
逐字出现时羽化向**框外**扩散（框内全清晰，首尾字都不发虚，文字不右移）；
隐藏阶段整行同时渐隐（100% → 0%）并按「隐藏像素」向左位移，两者同时发生。

## 硬约定（与根 AGENTS.md 一致）

### 文件与命名
- 主文件 `.jsx` **与目录同名**（`DialogueText/DialogueText.jsx`）—— `install.py` 按文件名部署。
- 源码 **UTF-8 with BOM + CRLF**；`install.py` 会自动补 BOM，但**别把行尾改成 LF**。
- 文件名里不要有空格。
- **每目录只允许一个 `.jsx`**：`verify.py` 发现多个会直接判失败。

### 版本号（三处单一真相）
`var VER` 常量 / `CHANGELOG.md` 顶部标题 / 面板顶部显示 —— **三处必须一致**，
`verify.py` 与测试都会校验。

为什么较真：ScriptUI Panel 由 **AE 启动时**载入 —— 改完不重启 AE，面板里跑的**还是旧版**，
AE 报的错可能是**旧文件**的行号。**没有版本号就无法判断 AE 里跑的是不是最新的。**

### 代码结构（顺序不可调）
```
一、标识与版本         VER / TOOL_ID / TOOL_TITLE / 所有魔法字符串与上限
二、纯逻辑层           只做数学与字符串/表达式文本生成, 绝不碰 AE API
三、测试导出闸门       if (typeof app === "undefined") { module.exports = ...; return; }
四、AE 层              日志 / safeRun / 图层与属性工具 / 蒙版 / 两种动画
五、UI 尺寸工具        pinW / fixedBox / addNote / addTextBox / addLabel / addNum / addDrop
六、UI 层              单页纵向 + 3 个 panel 分组 + 顶部主按钮/状态栏
七、主逻辑             readParams / updateModeUI / doApply / doRemove / doDiagnose
八、面板挂载           Panel 模式 vs 独立窗口
```
**闸门位置有硬约束**：所有纯函数之后、任何 AE API 之前，末尾必须 `return`。
上移 → 导出 `undefined`；下移 → node 下先执行 AE 代码而崩。

### 三条铁律（写工程的操作）
1. **先判前置条件**，缺失就「状态栏 + 弹窗」双提示 —— 只写状态栏，用户会以为"按钮坏了"。
2. **所有写操作包在一个 Undo 组**里，`finally` 里 `endUndoGroup()`；中途失败要主动删除本次改动。
3. **复用既有对象**（`findLayer` 找同名控制器）而不是重复创建。

### 所有 handler 必须经 `safeRun`
AE 的 ScriptUI handler 抛错是**完全静默**的（没有控制台）—— 这是"点击没反应"的根源。
`onClick` 与 `onChange` 都必须 `= safeRun(...)`，测试会数数量。

### UI 尺寸（模板承载的坑，别简化）
- `pinW` 必须写 **preferredSize / minimumSize / maximumSize 三处**，高度传 `-1`；
  **绝不**读回旧高度（刚建控件时可能是 0）。
- `fixedBox` 必须**先 `pinW` 再钉高度**；顺序反了宽度会被静默覆盖。
- 多行说明/调试图统一用 `addNote` / `addTextBox`，`scrolling` 属性做存在性回退。
- ⚠️ **禁用 `tabbedpanel`，也不要分页/下拉切页**：v0.1.0 用页签 → 真机整窗空白；
  v0.1.1 用「页面下拉 + group 显隐」→ 用户反馈「面板就不应该分页」。
- ⚠️ **挂载末尾必须有 `pal.layout.layout(true)`（Panel 分支）**：AE 的 ScriptUI Panel
  不会自动排版脚本动态添加的控件 —— 少了它，日志全绿、控件俱全，但**整窗空白**。
- **面板最小尺寸**：AE 会记住上次停靠尺寸，缩到 95×72 时整行控件被裁掉，
  用户会报「时间参数无法设置」。`buildUI` 末尾声明 `pal.minimumSize = [BOX_W+24, 300]`，
  `mountPanel` 对 `<200×200` 的尺寸写警告日志；排查"面板缺控件"先看这条日志。

## 本面板实现要点（改之前先读）

- **文本动画器位置 matchName 必须是 `ADBE Text Position 3D`**：
  用 `ADBE Text Position` 会报 `Can not add a property`。2D 名称只能作为后备候选，且必须排在 3D 之后。
- **滚动不改图层 `Position`**：用文本动画器 Position 偏移，图层排版与蒙版位置都不动。
- **窗口 = 段落框（段落文本）/ 文字外框（点文本）**：
  `baseRect = info2.windowRect ? info2.windowRect : info2.rect` 再 `computeBox(baseRect, ...)`；
  段落文本的 `windowRect` = 原 `boxTextPos` + 原 `boxTextSize`（宽高都不动），
  点文本 = `sourceRectAtTime` 的**层空间**文字范围。边距 0 = 紧贴窗口，正数外扩，负数内收。
  不再依赖合成宽高，多选时每层各自的框。框至少保留 `MIN_BOX` 宽高。
- **蒙版是静态 Shape**：`new Shape()` + `sh.vertices = buildMaskVertices(box)` + 零切线 + `closed`
  → `shape.setValue(sh)`；**不要再写路径表达式、不要用 `fromComp()`**。
  框在层空间，图层缩放/旋转时随文字一起变换。
- **羽化只作用左右，方向随模式变**（`fea.setValue([featherX, 0])`）：
  框贴合文字后，上下羽化会把文字上下缘吃淡。
  - 横向滚动 → **向内**：AE 蒙版羽化以路径为中心向两侧扩散，所以路径左右各内缩半个羽化
    （`computeFeatherInsetBox`），过渡区完全落在框内、**框外完全不可见**。
  - 逐字出现 → **向外**：向内羽化会把首尾的字吃掉（长文本尾部尤其明显），
    所以路径左右各外扩半个羽化（`computeFeatherOutsetBox`），框内完全清晰、过渡区全在框外。
  - 方向开关是 `applyWindowMask(layer, box, feather, strength, outward)` 的第 5 个参数；
    逐字出现必须传 `true`。
  羽化距离仍按 `scale/100` 反算，保证画面上的羽化宽度≈输入值。
- **羽化强度 = 蒙版不透明度**（`ADBE Mask Opacity`，0–100），不要改成别的语义。
- **滚动起止点由文本框左右边界决定**：边界是层空间常量，直接烘进表达式
  （`buildScrollExpression(rect.left, rect.width, box.left, box.right, ...)`）；
  文字左右缘在应用时测得并烘进表达式（表达式内不调用 `sourceRectAtTime`）。
- **动态曲线只改速度分布，不改起止点**：`easeProgress(k, startCurve, endCurve)` 是纯函数，
  先算 `a`（开头曲线）/ `b`（结束曲线），再按 `q = a*(1-k) + b*k` 加权；端点严格 0/1。
  组合语义：慢起+慢收 = 淡入淡出（smoothstep）；快起+慢收 = 前快后慢；慢起+快收 = 前慢后快。
  表达式里**内联展开**（`var a = k; … var b = k; … var q = …; var dx = s + (e-s)*q;`），不定义函数。
  默认两个下拉都是匀速 = 与 v0.4.0 行为完全一致；逐字模式不用曲线/方向，整组参数隐藏。
- **逐字出现分支必须建窗口蒙版**：滑出窗口的字要被裁掉；v0.6.0 的「原地不加蒙版」已作废。
- **逐字出现 = 一整套动画（出现 + 隐藏），只有两个模式**：
  - 方式是**两个互斥单选**（`rbScroll` / `rbType`），不是下拉；`MODE_TYPE_SCROLL` 与「字速」
    已在 v0.8.0 删除，旧值 2 由 `normalizeMode` 回落到横向滚动。**不要加第三个模式或字速。**
  - 方式读取统一走 `getMode()`；`updateModeUI()` 用 `grpScroll.visible` / `grpType.visible`
    显隐两套参数组，并调用 `pal.layout.layout(true)` 重新排版。
    **不要退回「下拉 + 逐个 enabled」**（v0.9.0 用户明确要求两套控制分开、选中哪个用哪个）。
  - 窗口 = 段落框（段落文本）/ 文字外框（点文本），**没有**独立「窗口宽」参数；边距为负会把窗口收窄。
  - 每字出现间隔 `step = (出现时长 - 单字渐隐) / (字数 - 1)`，
    `applyTypewriter(layer, info, params, timing.step, hideStart, hideEnd)` 直接传入；
    `hideStart = inPoint + lastVisible`、`hideEnd = inPoint + endTime`；
    最后一个字在「出现时长」末尾完成。
  - 只有一个位置动画器 `DT_滚动`，位置表达式 `buildTypeScrollExpression`（**不再接收羽化宽**）分两段：
    前沿按**文本框边界**算：`ks = t / step + 1`（把正在画的字宽算进前沿，夹 0..n）、
    `dx = br - (文字左缘 + 平均字宽 × ks)`，上限 **0**（文字绝不右移）、
    下限 `dxEnd = min(0, br - 文字右缘)` —— 零/正边距时 `dx ≡ 0`，出现阶段文字**完全不动**；
    只有负边距（框比文字窄）时，前沿到框右缘后整行才左移；
    隐藏阶段（`t > 出现时长`）从 `dx0 = dxEnd`（与出现结束连续，不跳）线性向左推
    `隐藏像素`（层空间 = 面板像素 / 图层缩放）。
    ⚠️ **不要重新引入「右移避羽化」（`shift = 清晰区左缘 - 文字左缘`）**：
    框 = 文字时它会把文字右缘推出框外，长文本尾部几个字整套落在羽化/框外，
    只能等隐藏阶段滑出来（v0.11.5 真机修复的就是这个）。
    **`DT_滚动` 只挂位置，绝不挂不透明度**（见下一条）。
  - **隐藏阶段 = 整体渐隐 + 左移，两者同时发生**（v0.11.0 用户明确要求）：
    整体渐隐写进**每个字自己的**不透明度动画器（v0.11.4 起）——
    出现关键帧 `0 → 100` 之后追加 `hideStart → 100`、`hideEnd → 0`，全部 LINEAR；
    所有字在同一区间渐隐，视觉上就是整行渐隐。
    ⚠️ **不要**把整体渐隐挂到一个选区覆盖 0-100% 的动画器（如 `DT_滚动`）上：
    AE 文本动画器的不透明度会**覆盖**同字符其他动画器的结果，
    全行 100% 会把每字动画器的 0 → 100 顶掉，整行从 0 秒就可见、**逐字出现消失**
    （v0.11.1~v0.11.3 真机复现，v0.11.4 修复）。
    ⚠️ 文本动画器 Opacity 是**目标不透明度**（100 = 不变，0 = 全透明），
    脚本取值范围 **0..100**，写 `-100` 会报「值 -100 在 0 至 100 的范围外」。
    **不要改成图层自身 Opacity**。`隐藏像素` 只负责同一时间段里的左移距离，0 = 原地渐隐。
  - 关键帧写入失败时，catch 里要把最后一个关键帧写回 `100`，避免字被留在全透明状态。
  - 所有 catch 里的错误对象必须经 `errText()` 转字符串再拼接，否则会「报错时又报错」。
  - 默认值：渐隐 0.12 / 出现 2.0 / 隐藏 0.8 / 隐藏像素 100 / 羽化 25 / 强度 100 / 边距 0。
  - 羽化/隐藏像素都按图层缩放反算到层空间（羽化只作用于蒙版，不再进位置表达式）。
  - 出点延长到 `出现时长 + 隐藏时长`。
  - 零边距时框宽 = 文字宽，出现阶段文字**完全不动**（`dx ≡ 0`），这是几何必然；别为此加假左移。
- **逐字出现用「每字符一个 Animator + Opacity 关键帧」**，每个选择器 Smoothness = 0；
  不要改回 Range Selector Smoothness 的整体做法（首尾边界行为不确定）。
  **选区单位必须用索引，且每个动画器分别切**：`setSelectorIndexMode` →
  `Units=Index(2)` + `Based On=Characters(1)`，再写
  `ADBE Text Index Start/End` = `selIdx / selIdx+1`，精确只选第 selIdx+1 个**可见**字符
  （`selIdx` = 非空白字符序号，0 基，来自 `countVisibleChars`）；
  ⚠️ **AE 26 真机：索引单位下空格不占索引**（官方帮助说「依据=字符」数空格，实测不数）——
  必须用 `selIdx`，不能用原文下标 `i`：空格被跳过后，原文下标会让空格后第一个字
  没有任何动画器覆盖、从 0 秒起一直显示，后面所有字也整体早一拍（v0.11.11 修复）；
  百分比 `i/n*100` 在 n 不能整除 100 时会被 AE 按字符边界取整，
  把相邻字并进同一个动画器 ⇒ 该字从 0 秒起一直显示（v0.11.10 修复）；
  ⚠️ 切到索引后百分比那对 Start/End 是**隐藏属性**，再写会报
  「无法将 set value 与此属性一起使用…被隐藏」；两对显示名都叫 Start/End，
  必须按 matchName 取。索引属性取不到就切回百分比，**绝不混用**。
  选区获取要**防御性**：`if (selGroup.numProperties > 0) sel = selGroup.property(1)`，
  取不到才 `addRangeSelector`，避免不同 AE 版本自带默认选区时多出一个；
  三处动画器创建（`applyScroll` / `applyTypeScroll` / `applyTypewriter`）同一写法。
- **应用顺序：先清理旧动画，再测量文字范围**。
  `sourceRectAtTime` 会把旧滚动表达式的位移算进去，顺序反了起止点会偏。
- **段落文本（框文本）必须先解决溢出再测量，且不能拉高用户的框**：
  AE 会**隐藏**超出定界框的文字（只留溢出图标，官方《创建和编辑文本图层》），
  被裁的行既看不到也演不到 —— 表现为「逐字演到约 2 秒就停、出现 6 秒像没生效」。
  做法 `fitParagraphBox`：**先用官方 `TextDocument.boxOverflow` 判定**（AE 24.6+），
  `false` ⇒ 全部文字都在框内，**完全不动用户的框**；
  `true` ⇒ 把**排版框单行化**：框高设为 `max(原框高, ceil(行距))`（一行高），
  宽度用「倍增 + 二分」找到能装下整行的最小宽度写回 `boxTextSize`；
  写回后再读一次 `boxOverflow` 复核，仍溢出或任何失败一律还原。
  **窗口 = 用户原框**（原 `boxTextSize` + `boxTextPos`，宽高都不动）；
  原框尺寸存进蒙版名 `DT_窗口 595x49`，重复应用靠 `readStoredWindow` 找回。
  ⚠️ `boxOverflow` / `composedLineCount` 是**组合时快照**：每次判定都必须在
  `setValue` 之后重新 `st.value` 取新的 TextDocument，不能复用旧对象。
  ⚠️ 框变化后要把 `boxTextPos` 恢复原值（AE 可能以中心为基准缩放框，文字会跳）。
  ⚠️ 旧版 AE 没有 `boxOverflow` 才退回 v0.11.6 的「撑高后测 sourceRectAtTime」；
  该法若量到的高度 ≈ 撑高值，说明返回的是框尺寸，必须还原并告警，不要当成没溢出。
  ⚠️ 框高小于一行（行距）⇒ 告警；文本含强制换行 `\r` ⇒ 还原并告警；
  源文本有 `numKeys`/`expressionEnabled` 时不要写 doc。
- **清理按名称前缀**：动画器 `DT_滚动` / `DT_渐隐**`，蒙版 `DT_窗口`。
  新增动画器命名必须落在这两个前缀里，否则「移除动画」清不掉。
- **参数可反复调整**：改完参数再点「应用动画」即重建；不要做「只在首次应用」的缓存。
- **不要创建空对象控制器**：v0.2 的 `DT_左消失点` / `DT_右消失点` 已被 v0.3.0 移除，
  v0.4.0 起出现窗口由「文字范围 + 四边边距」决定，v0.11.8 起段落文本改用「你给的原段落框」。
- **属性取用一律 `getPropSafe` 多候选回退**，失败写 `diag`，不要直接抛。
- **桌面日志是排障入口**：`Folder.desktop/DialogueText_debug.log`，失败回退 `Folder.temp`；
  `flog()` 只进内存，最多每 800ms 整文件写一次（`LOG_WRITE_GAP`），
  挂载完成 / handler 结束 / 出错时 `flushLog()` 强制落盘 ——
  不要改回「每条日志立即写文件」，桌面被网盘同步时会明显拖慢首次加载。
  新增关键步骤请补 `flog`，滚动 / 逐字左移表达式全文已写日志，便于真机核对。
- **说明文字一律 `statictext`**（`addNote`）：不要用只读 `edittext`，
  AE 里它是白底且内容超出会带滚动条，用户已明确反馈不要这种外观。
- **诊断优先于猜测**：UI 构建整体包在 `try/catch` 里；失败走 `buildErrorUI()` 兜底界面
  （先清空半成品控件，再显示日志 + 复制 + 打开）。
