# 对话文本动画 DialogueText

给时间轴上**已排好版的文本图层**就地加动态：**不改文字、不改字体字号、不改图层位置**，
只在图层内加文本动画器 + 一个**出现窗口蒙版**（段落文本 = 你给的段落框；点文本 = 贴合文字的外框）。
文字只在窗口内出现，窗口外不显示。

- 版本：**v0.11.11**（已真机验证）
- 适用：After Effects 2015.3 – 2026（ExtendScript / ScriptUI Panel）
- 安装：`panels/DialogueText/DialogueText.jsx` → AE 的 `ScriptUI Panels` 目录，重启 AE 后在 `Window > Extensions` 打开

## 快速开始

1. 在时间轴里**激活一个合成**，选中一个或多个**文本图层**（可按住 Shift/Ctrl 多选）。
2. 打开面板，先在顶部选**方式**（二选一，不是多选）：
   - `横向滚动`：显示方向 / 时长 / 开头曲线 / 结束曲线；
   - `逐字出现`：显示渐隐 / 出现 / 隐藏 / 隐藏像素；
   - **文本框**：左边距 / 右边距 / 上边距 / 下边距（px，0 = 紧贴文字）；
   - **羽化(px)** 与 **强度(%)**：两种方式共用，始终显示。
3. 点 **「应用动画」**。
4. **继续调整**：改任意参数，再点一次「应用动画」即可更新 ——
   会先按名称清掉本工具旧动画/蒙版，再按新参数重建，不会叠加。
5. 撤销：`Ctrl+Z` 一次整体撤销本次应用；或选中图层点「移除动画」。

## 两种方式

### 横向滚动

以**文字当前所在范围**生成一个固定文本框，整行文字在这个框内滑过：
从框外一侧进入，穿过框，从另一侧离开。

- `从右往左`：文字从文本框右边进入，向左离开；
- `从左往右`：文字从文本框左边进入，向右离开；
- 滚动从**图层入点**开始，时长由「时长(秒)」决定，结束后停在终点；
- 零边距时文字行程 = 2 倍文字宽，不会横穿整个画面。

### 动态曲线（仅滚动）

曲线只改变**速度分布**，不改变起止点与总时长：

| 想要的效果 | 开头曲线 | 结束曲线 |
|---|---|---|
| 匀速（默认，与旧版一致） | 匀速起步 | 匀速收尾 |
| **淡入淡出**（两端慢、中间快） | 慢起加速 | 减速慢收 |
| **前面快、后面慢** | 快起减速 | 减速慢收 |
| **前面慢、后面快** | 慢起加速 | 加速快收 |

- `慢起加速` = 开头慢、越走越快；`快起减速` = 开头快、越走越慢；
- `减速慢收` = 结尾慢慢停；`加速快收` = 结尾加速冲出去；
- 两个下拉可以自由组合，端点严格对齐起止位置，不会跳变；
- 数学上：`q = a*(1-k) + b*k`，其中 `k` 是时间进度，
  `a` 由开头曲线决定、`b` 由结束曲线决定；组合结果见上表。

### 逐字出现

一整套动画：窗口里从左往右逐字出现；打满窗口后整行左移让位；
最后一个字出现后，整行用「隐藏(秒)」渐隐并同时左移（被蒙版裁掉）。

- **窗口 = 段落框（框文本）/ 文字外框（点文本）**，不用另外填宽度；
- **出现(秒)**：整句所有字出现完的总时长，内部自动换算成字间隔；
- **单字渐隐(秒)**：每个字自己的淡入时长；
- **隐藏(秒)**：最后一个字出现后，整行**不透明度 100% → 0%** 的用时；
- **隐藏像素**：同样是这段隐藏时间里，整行向左位移的距离（画面像素）。
  默认 100；0 = 原地渐隐；调大到渐隐结束前整行滑出窗口；
- **羽化放在框外**：逐字出现的窗口 = 段落框/文字外框，**羽化向框外扩散**，
  框内的字从出现那一刻起就是实心的（首尾字都不会发虚），所以文字不需要再右移；
- 左移条件：只有**文本框比文字窄**（右边距填负数）时，打字前沿到框右缘才整行左移。
  零/正边距时出现阶段文字**完全不动**，每个字都在自己的位置上逐字出现；
  **想让它中途就左移，把右边距填负数**（把窗口收窄），例如 -200；
- 会创建窗口蒙版（框外文字不可见），逐字出现的羽化向框外扩散（框内全清晰）；
- 图层出点会自动延长到「出现 + 隐藏」结束。

## 文本框与羽化

| 参数 | 默认 | 说明 |
|---|---|---|
| 左边距 / 右边距 | 0 | 相对**出现窗口**（段落文本=你给的段落框，点文本=文字外框）：0 = 紧贴窗口，正数向外扩，负数向内收（px） |
| 上边距 / 下边距 | 0 | 同上，控制框的上下边界 |
| 羽化(px) | 25 | 文本框**左右边缘**的过渡宽度；横向滚动向框内扩散，逐字出现向框外扩散；0 = 硬边 |
| 强度(%) | 100 | 直接写入**蒙版不透明度**；100 = 完全保留，越低框内越透明 |

- 出现窗口按每个文本层**各自生成**（多选时每层一个框）：段落文本 = 你给的段落框（宽高都不动），点文本 = 文字范围；都站在文字原来的位置不动。
- 框是**层空间**下的矩形：图层有缩放/旋转时，框跟着文字一起变换；框外文字**完全不显示**。
- **羽化只作用在左右边缘**：横向滚动时蒙版路径各内缩半个羽化（框外完全不可见）；
  逐字出现时各外扩半个羽化（框内完全清晰，首尾的字不被羽化吃掉）；上下边界用边距控制即可。
- 羽化距离会按图层缩放反算，保证画面上的羽化宽度≈面板输入值。
- 边距不会把框挤没：至少保留 2px 宽高（`MIN_BOX`）。

## 参数

| 参数 | 默认 | 适用 | 说明 |
|---|---|---|---|
| 方式 | 横向滚动 | — | **两个互斥单选**：横向滚动 / 逐字出现；选中哪个就只显示哪套参数 |
| 方向 | 从右往左 | 滚动 | 从右往左 / 从左往右 |
| 开头曲线 | 匀速起步 | 滚动 | 匀速起步 / 慢起加速 / 快起减速 |
| 结束曲线 | 匀速收尾 | 滚动 | 匀速收尾 / 减速慢收 / 加速快收 |
| 时长(秒) | 3.0 | 滚动 | 从入点开始，整行滑完所需时间 |
| 渐隐(秒) | 0.12 | 逐字出现 | 单字符淡入时间 |
| 出现(秒) | 2.0 | 逐字出现 | 整句所有字出现完的总时长 |
| 隐藏(秒) | 0.8 | 逐字出现 | 整行渐隐到 0 的用时 |
| 隐藏像素 | 100 | 逐字出现 | 渐隐期间向左位移的距离（px）；0 = 原地渐隐 |
| 羽化(px) | 25 | 两种 | 文本框左右边缘过渡宽度 |
| 强度(%) | 100 | 两种 | 蒙版不透明度 |
| 左边距/右边距/上边距/下边距 | 0 | 两种 | 相对文字外框的边距（px，可负） |

- 参数不持久化，关闭面板后回到默认值；「重置参数」可一键恢复。
- 单次最多处理 50 个文本层；逐字模式单层最多 2000 字符、合计最多 5000 字符。

## 实现要点（看得懂就不怕改）

- **只加动画，不动排版**：滚动用文本动画器的 `Position` 偏移（`ADBE Text Position 3D`），
  不写图层 `Position`；逐字用 `Opacity` 动画器 + 关键帧。
- **出现窗口 = 1 个静态矩形蒙版**（`DT_窗口`，`MaskMode.ADD`）：
  顶点取自出现窗口（段落文本 = `boxTextPos` + 原 `boxTextSize`；点文本 = `sourceRectAtTime` 文字范围）加四边边距，
  用 `new Shape()` 写入蒙版路径；羽化距离/强度分别写蒙版羽化与蒙版不透明度。
- **滚动起止点由文本框左右边界决定**：边界是层空间常量，应用时直接烘进表达式；
  文字左右缘同样在应用时测得并烘进表达式。
- **速度曲线内联在表达式里**：`buildScrollExpression` 按两个下拉生成
  `a / b / q = a*(1-k)+b*k`，表达式内不定义函数，也不改起止点。
- **羽化方向随模式变**：横向滚动用 `computeFeatherInsetBox`（路径各内缩半个羽化，
  过渡区全在框内、框外完全透明）；逐字出现用 `computeFeatherOutsetBox`
  （路径各外扩半个羽化，过渡区全在框外、框内完全清晰）。
- **逐字出现 = 每字动画器（出现 + 隐藏渐隐）+ 一个位置动画器**：
  每字动画器负责出现（`step = (出现时长 - 单字渐隐) / (字数 - 1)`），
  选区**复用动画器自带的默认选区**（`selectors.property(1)`），不再追加第二个选区；
  其不透明度关键帧为 `0 → 100`（出现），再追加 `100 → 0`（隐藏阶段，所有字同一区间，
  视觉上整行一起渐隐）。**不要再把整体渐隐挂到覆盖全行的 `DT_滚动` 上** ——
  它的 100% 会覆盖每字动画器的结果，逐字出现直接消失（v0.11.4 真机确认修复）。
  `DT_滚动` 的 Position 表达式（`buildTypeScrollExpression`）分两段：
  出现阶段前沿按**文本框边界**推进（`dx = br - (rl + avg*ks)`，上限 0、下限 `br - rr`）——
  零/正边距时 `dx ≡ 0`，文字完全不动，每个字都在自己的位置上逐字出现；
  只有负边距（框比文字窄）时，前沿到框右缘后整行才左移；
  出现结束后用隐藏时长把 `dx` 从出现结束时的位置线性推到左侧（位移 = 隐藏像素），
  整行滑出被蒙版裁掉；只加动画器属性、不改图层自身 Opacity。
  窗口 = 段落框（段落文本）/ 文字外框（点文本）（`computeBox`），边距为负会把窗口收窄、更早开始左移。
- **说明文字是静态文本**：`addNote` 用 `statictext`，不再创建白底只读输入框与滚动条。
- **日志节流**：`flog` 先进内存，最多每 800ms 整文件写一次；
  挂载完成 / 操作结束 / 出错时 `flushLog()` 强制落盘，首次加载只写一次。
- **重应用不叠加**：应用前按名称清理本工具的动画器（`DT_滚动` / `DT_渐隐**`）和蒙版（`DT_窗口`）。
- **先清理再测量**：否则旧滚动表达式的位移会被 `sourceRectAtTime` 算进文字范围。
- **单 Undo 组**：失败时回滚本次加的动画器/蒙版。

## 调试日志

面板会把启动与操作日志写到桌面：

```
C:\Users\<你的用户名>\Desktop\DialogueText_debug.log
```

- 每次 AE 启动载入面板时**清空重写**；记录脚本路径、AE / ExtendScript 版本、宿主类型、
  `safeRun` 的操作开始/完成/异常（行号、文件、错误号、堆栈）、滚动表达式全文。
- 为加快首次加载，日志改为**节流落盘**：先在内存累积，最多每 800ms 写一次；
  面板挂载完成、操作结束、出错时立即强制写入；最多保留 2000 行。
- 日志里每层会打印 `文本框(层空间): [左,上] - [右,下]`，可据此核对框的位置。
- 桌面不可写时回退系统临时目录，日志首行写明实际路径。
- 底部「输出与调试」区：**显示日志 / 复制日志 / 打开日志 / 诊断**（这是唯一保留的多行框）。
- 若面板整窗空白：先看顶部版本号是否为 `v0.11.11`（不是说明 AE 没真正重启），
  再打开桌面日志看最后的 `布局完成: 面板 WxH / 首选 WxH`；
  UI 构建真抛错时会进**兜底界面**（日志 + 复制 + 打开）并弹窗给出日志路径。

## 已知限制

- 只处理文本层；非文本层会被跳过并在日志里注明。
- 出现窗口在**应用时**确定一次：段落文本用你给的原框，点文本按文字范围；应用后再改文字内容/字号/段落框，窗口不会自动跟着变，需重新应用。
- 图层有极端旋转时，滚动方向沿图层自身的 x 轴（框与文字一起转）。
- 蒙版/动画器按**名称**识别，不要重命名 `DT_窗口` / `DT_滚动` / `DT_渐隐**`。
- 羽化强度是蒙版不透明度：数值低于 100% 时，**框内整体**都会变透明，而不只是边缘。
- 羽化只作用左右边缘，上下边是硬边；横向滚动向框内扩散（框外不可见），
  逐字出现向框外扩散（框内全清晰）。
- 逐字模式每个字符一个动画器：长句会产生较多属性（上限见参数表）。
- 逐字出现按**平均字宽**估算打字前沿（`文字宽 / 字数`），
  含大量英文/标点混排时，字与字的节奏会有轻微差异。
- 逐字出现的窗口 = 段落框（点文本 = 文字外框）；零/正边距时出现阶段文字完全不动，
  想中途左移请用负右边距收窄窗口（窗口比整行窄 → 打满后整行左移）。
- 文本层若是**段落文本（框文本）**：AE 本身会隐藏超出定界框的文字，应用时脚本会把
  框高自动收到刚好容纳全部文字（宽度/换行不变）；若日志提示「源文本有动画」则不会改框，
  需要手动把定界框拉高到文字全部可见。
- 参数不持久化。
