# 更新日志（CHANGELOG）

## v2.0.5（当前版本）

- **透明度/字号改为"二值 + 滚动过渡"**：静止时中心组 = 最大透明度+最大字号，其余组 = 普通透明度+普通字号（不再渐变）；滚动过程中字号/透明度平滑过渡
- **修复"透明度看不出区别"根因**：d（组到画面中心距离）基准错误——原用 `|ctrlY - H/2|`（中心组算出来 ≈290px），改为按句所属组 `|ctrlY + gi*step - (mnum-1)/2*step - H/2|`（中心组 d=0）
- 过渡带 = step（组步长）：`ease(dd, 0, step, 最大, 普通)`
- 模拟测试增至 **24 项断言**（新增二值/过渡/组一致性验证）

## v2.0.4

- **修复播放错位/跳动**：句位置偏移公式由 `(rel - idx*step)` 修正为 `(rel - ((mnum-1)/2)*step)`（固定偏移），歌词整体位置与滚动动画恢复正常
- 新增 Node 模拟测试 `test_rolling_lyrics_v2.js`（14 项断言：布局/滚动连续性/整组跟随/缩放一致性/组内间距），表达式算法部署前先在 Node 验证，杜绝盲发
- 所有表达式显式 `var` 声明

## v2.0.3

- 修复：生成时 buildController 漏传 `linesPerScroll` / `multiGap`，导致「组内行间距」控件 `setValue(undefined)` 报错（第 434 行）

## v2.0.2

- 滚动帧数默认 30 → **9**；停顿帧数默认 20 → **30**

## v2.0.1

- 默认参数调整：最大字号 60 / 普通字号 40 / 两句间距 145 / 最大透明度 100 / 普通透明度 30
- 组内行间距默认对齐"两句间距"（145）；滚动帧数 30 / 停顿帧数 20 / 抖动帧数 ±10 不变

## v2.0.0

- 基于 v1 v3.7 迭代开发；**v1 文件（panels/AE-Rolling-Lyrics/）冻结不动**
- 新增「**滚动句数**」：1 / 2 / 3 句一起滚动（面板下拉选择，默认 1 句 = v1 行为；生成后可在 AE 的 Lyrics_Ctrl「滚动句数」控件实时修改）
- 新增「**组内行间距**」：N 句组内的行间距 (px)，仅 >1 句时生效（默认 140，与"两句歌词间距"一致）
- 滚动 / 缩放 / 透明度改为按「组」计算：**整组同时滚动、整组到中心一起放大变亮**
- 预设版本 v2 → v3：新参数纳入预设（短键 `lps` / `mg`），旧预设自动兼容回退
- 其余功能与 v1 一致：参数控件化、预设双层持久化、超长句自动缩窄、停顿随机
