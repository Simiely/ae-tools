# 更新日志（CHANGELOG）

## v2.0.2（当前版本）

- 滚动帧数默认 30 → **9**；停顿帧数默认 20 → **30**

## v2.0.1

- 默认参数调整：最大字号 60 / 普通字号 40 / 两句间距 145 / 最大透明度 100 / 普通透明度 30
- 组内行间距默认对齐"两句间距"（145）；滚动帧数 30 / 停顿帧数 20 / 抖动帧数 ±10 不变

## v2.0.0

- 基于 v1 v3.7 迭代开发；**v1 文件（panels/AE-Rolling-Lyrics/）冻结不动**
- 新增「**滚动句数**」：1 / 2 / 3 句一起滚动（面板下拉选择，默认 1 句 = v1 行为；生成后可在 AE 的 Lyrics_Ctrl「滚动句数」控件实时修改）
- 新增「**组内行间距**」：N 句组内的行间距 (px)，仅 >1 句时生效（默认 140，与"两句歌词间距"一致）
- 滚动 / 缩放 / 透明度改为按「组」计算：**整组同时滚动、整组到中心一起放大变亮**
- 预设版本 v2 → v3：新参数纳入预设（短键 `lps` / `mg`），旧预设自动兼容回退
- 其余功能与 v1 一致：参数控件化、预设双层持久化、超长句自动缩窄、停顿随机
