# 滚动歌词生成器 V2 (Rolling Lyrics Generator V2)

After Effects 2026 歌词滚动工具（v1 v3.7 的迭代版，**v1 冻结不动**）。

**V2 新能力**：可以选择 **N 句歌词一起滚动**（填任意 ≥1 的数字，默认 1 句 = 与 v1 行为一致），并控制组内行间距。

## 特性

- 自动按行拆分歌词，每句一个图层；`Lyrics_Ctrl` 空对象驱动整体滚动
- **滚动句数（V2 新增）**：**任意句数（≥1）**一组同时滚动；滚动到画面中心时**整组一起放大、一起变亮**
- **组内行间距（V2 新增）**：N 句组内两句之间的间距 (px)，仅 >1 句时生效
- **水平对齐（V2 新增）**：左对齐 / 居中 / 右对齐（默认居中）；生成后可实时改
- 参数全部控件化：生成后选中 Lyrics_Ctrl，在效果控件里直接改（含滚动句数/组内行间距/水平对齐）**实时生效**
- 停顿随机（每句停顿 ± 抖动）、超长句自动缩窄、预设双层持久化

## 安装（免安装）

1. 把 `rolling-lyrics-v2.jsx` 复制到 AE 脚本面板目录：
   ```
   %APPDATA%\Adobe\After Effects\26.0\Scripts\ScriptUI Panels\
   ```
   （或用 ae-tools 仓库根 `python install.py` 一键部署全部）
2. 重启 AE（脚本面板启动时扫描）。
3. 菜单「**窗口 › 扩展 › rolling-lyrics-v2**」打开面板。

> 与 v1（rolling-lyrics）在菜单里共存；**同一合成请只用同一版生成**（两版共用 Lyrics_ 前缀图层命名，混用会互相清理）。

## 快速开始

1. 激活一个合成（可选：选中一个文本图层以继承字体/颜色样式）。
2. 在面板「歌词」输入框粘贴歌词（每句一行），或留空用选中文本图层。
3. 填「滚动句数」：任意 ≥1 的数字（如 1 / 2 / 4 / 10）；>1 时设置「组内行间距」。
4. 选「水平对齐」：左对齐 / 居中 / 右对齐（默认居中）。
5. 点「**生成滚动歌词**」。完成后可选中 Lyrics_Ctrl 空对象，在效果控件里实时调整所有参数。
