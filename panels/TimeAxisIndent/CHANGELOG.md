# 更新日志(CHANGELOG)

## v1.7.1(当前版本)

- 自定义文字默认值调整:输入框默认填入竖线 `|`,位置默认「缩进符号前」
- (此前默认空文字 + 缩进符号后)

## v1.7

- 新增「替换所有文字」复选框(自定义文字组下方)
- 勾选后点「应用错位」:图层名**整体变为**「缩进+自定义文字」,原图层名丢弃(批量统一命名),仅 Ctrl+Z 可恢复
- 自定义文字为空时提示并中止,避免把名字替换成纯缩进
- 与位置/等距/递进联动:文字位置、缩进阶梯均生效
- 回归:60 项模拟测试全部通过

## v1.6.1

- 「全部清除」增强:从左往右剥离**所有**树形缩进,即使中间隔着文字(如 `├- 【M】├- 图层` → `图层`)
- 被树形符号夹住的文字块一并删除;行首文字 / 普通文字中间的空白保留(不误删)
- 配合输入框文字,可删除缩进后的自定义文字(如 `├- ├- 【M】图层` → `图层`)
- 回归:56 项模拟测试全部通过

## v1.6

- 新增「自定义文字」输入框 + 位置选项(缩进符号前 / 缩进符号后,默认后)
- 应用时在缩进前缀旁附带自定义文字(如分组标记):`【M】├- 图层` 或 `├- 【M】图层`
- 叠加模式按「旧层数 + 本次层数」逐次加深,自定义文字只保留一份,可随时切换位置
- 还原/清空重排按位置顺序一并剥离自定义文字;输入框文字留空则保留旧文字(不误删)
- 修复:叠加逻辑重写时误引入"重复应用不递增"回归(计数法重建)
- 回归:51 项模拟测试全部通过

## v1.5

- 操作结果不再用 alert 弹窗,改为面板底部**状态栏**即时显示
- "没有可处理的图层"等提示同样进状态栏;仅"未激活合成"保留弹窗
- 回归:38 项模拟测试全部通过

## v1.4

- 新增「应用方式」下拉:**叠加缩进 / 清空重排**(默认叠加)
- 叠加:每次应用直接追加一层(1 格 → 2 格 → 3 格),同风格/多风格均可累积
- 重排:先清除所有旧缩进,再按本次参数统一应用
- 作用范围(选中/全部)只决定处理哪些图层,与叠加/重排解耦
- 测试增至 38 项

## v1.3

- 树形符号由 `├─ ` 改为 `├- `(半边横线)
- 默认参数:缩进量 1 格 + 缩进字符树形
- 缩进字符选项去掉「半角空格」,仅保留 全角空格 / 树形符号
- 旧版本半角缩进仍可用「全部清除」清理

## v1.2

- 修复 ScriptUI Panel **双窗口**问题(空 Panel + 新 Window 并存)
- 根因:未接住 AE 顶层 `this`,按官方标准模式 `(thisObj instanceof Panel) ? thisObj : new Window(...)` 重写

## v1.1

- 按字符风格精确剥离:不再误删用户原始装饰字符(如 `───`、前导空格)
- 多风格共存 + 按风格/批次分别还原
- 还原只剥"行首最外层"同风格前缀,叠加需从外往内逐层剥
- Undo 组 try/finally 保护
- 模拟测试驱动修复(10 方案 + 3 组 bug 对照,33 项断言)

## v1.0

- 初版:时间轴图层假缩进(全角/半角空格、树形符号),等距/递进,一键还原
- 仅改图层名,不影响父子结构、动画与渲染;无插件时工程照常打开
