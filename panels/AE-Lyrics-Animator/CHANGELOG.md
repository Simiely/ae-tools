# 更新日志（CHANGELOG）

本文件记录每个版本的变更。分类：`新增` / `修复` / `重构` / `样式`。

## v3.5（当前版本）

### 新增
- 字间距动态效果：初始 → 结束字间距线性变化，逐字独立控制
- 预设双层持久化：工程目录 JSON + app.settings 全局保底，优先读工程 JSON

### 修复
- ExtendScript 无内置 JSON 对象导致预设文件为空（注入 JSON polyfill）
- 字间距值 `* 0.1` 缩放，匹配 AE 面板直观感受

### 重构
- 代码模块化：UI 工厂函数、动画子函数拆分、`DEFAULTS` 集中管理
- 合并重复辅助函数：`setBlur` / `getDirectionPos` / `removeLyricsAnimators`
- 表达式构建改为数组 `join`，可读性提升

## v3.4

### 重构
- 提取 `setBlurValue` 辅助函数，消除重复
- `clearAnimators` 复用 `findAnimatorsGroup`

### 修复
- 出场模糊变量语义修正

## v3.3

### 样式
- 标签 110px + 输入框双轴 fill 撑满，布局整洁

### 修复
- Blur 表达式 2D 兼容（需返回 2D `[x, y]`）
- 绝对时间括号截断

## v3.2

### 新增
- 面板独立总开关（每个动画器模块可单独启用）
- 入场 / 出场支持「逐字 / 一起」两种模式

## v3.1

### 新增
- 入场 / 出场方向选择（左 / 右 / 上 / 下）
- 随机模糊效果（种子可控）
- 散落时间控制（渐入过渡）

## v2.0

### 新增
- 散落分布：随机位置 + 随机大小（种子可复现）
- 四合一动画器整合

## v1.x

### 新增
- v1.1：入场 + 出场 + 波动（波浪）效果
- v1.0：高度错落（逐字波浪）基础版
