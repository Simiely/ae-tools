# tips · 使用技巧知识库

本目录收录 After Effects 使用技巧，与 `panels/` 插件源码分离管理：

- **插件 README** 管「怎么用」：功能说明 + 基本操作
- **本目录** 管「用得巧 / 踩过坑」：进阶玩法、经验沉淀、速查

> 边界：开发规范 / 项目规则 / ES3 速查表在独立仓库 `Simiely/knowledge-base`，本目录只收录**使用层面**的技巧，二者不混。

## 分类导航

| 分类 | 目录 | 内容 |
|---|---|---|
| AE 通用技巧 | [ae/](ae/README.md) | 快捷键、表达式、渲染导出、常见坑 |
| 插件使用技巧 | [tools/](tools/README.md) | 本仓库 9 个自写插件的进阶用法 |

## 新增一篇技巧的约定

1. 按分类放入对应目录（`ae/` 或 `tools/`）
2. 文件名：英文小写 + 连字符（如 `shortcuts.md`、`quickkey.md`），插件技巧与 `panels/` 目录名一一对应
3. 每篇文件头统一格式：

```markdown
# 标题

> 适用版本：AE 2026（26.0）中文版
> 相关插件：xxx（无则省略）
> 创建：YYYY-MM-DD · 更新：YYYY-MM-DD
```

4. 更新对应分类的 `README.md` 索引
5. 若技巧涉及具体插件，在插件 `panels/<Tool>/README.md` 里加一条反向链接
