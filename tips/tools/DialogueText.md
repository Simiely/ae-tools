# DialogueText · 使用技巧

> 适用版本：AE 2015.3 – 2026
> 相关插件：对话文本动画（`panels/DialogueText/`）
> 创建：2026-11-25 · 更新：2026-11-25（v0.11.11）

## 一句话记住核心设计

> **选中现有文本层 → 按「出现窗口」加一个固定蒙版 + 文本动画器。**
> 段落文本（框文本）的窗口 = **你给的段落框**；点文本的窗口 = 贴合文字的外框。
> 文字只在窗口内出现，窗口外不显示；四边边距、羽化距离、羽化强度都在面板里输入。

文字、字体、字号、图层位置都不改，所以排版可以放心先做好。

> 面板顶部的方式是**两个互斥单选**：选中「横向滚动」只显示滚动参数，
> 选中「逐字出现」只显示逐字参数（不是多选，也没有下拉）。

## 常用操作速查

| 目标 | 操作 |
|---|---|
| 整行从右滚到左 | 方式「横向滚动」+ 方向「从右往左」 |
| 整行从左滚到右 | 方式「横向滚动」+ 方向「从左往右」 |
| 淡入淡出（两端慢） | 开头曲线「慢起加速」+ 结束曲线「减速慢收」 |
| 前面快、后面慢 | 开头曲线「快起减速」+ 结束曲线「减速慢收」 |
| 前面慢、后面快 | 开头曲线「慢起加速」+ 结束曲线「加速快收」 |
| 一个字一个字冒出来 | 方式「逐字出现」，填「出现(秒)」控制整句打完的时间 |
| 逐字出现 + 满窗左移 + 整行渐隐 | 方式「逐字出现」，再填「隐藏(秒)」 |
| 像字幕机一样打完再淡出 | 逐字出现：出现 1.5–3、隐藏 0.6–1.2、隐藏像素 100–400 |
| 打字中途就开始左移 | 逐字出现 + 右边距填负数（把窗口收窄） |
| 只保留文字原位置附近可见 | 保持默认边距 0（段落文本=你给的段落框，点文本=文字外框）；想多留空间就加正边距 |
| 框比文字更小 / 更紧凑 | 左/右/上/下边距填负数（向内收） |
| 两端渐隐更柔 | 羽化 25 → 60（太大时两端会互相吃掉） |
| 让框内文字更淡 | 降低「强度(%)」（= 蒙版不透明度） |
| 重做一遍 / 改参数 | 直接再点「应用动画」，旧动画会先按名称清掉，不叠加 |
| 只撤销本次应用 | `Ctrl+Z` 一次（整批在一个 Undo 组里） |
| 彻底移除 | 选中文本层 → 「移除动画」 |
| 面板空白 / 按钮没反应 | 打开桌面 `DialogueText_debug.log`，把内容发回 |

## 进阶用法

### 1. 先排版，再加动画

推荐顺序：

1. 在 AE 里把文字的位置、字体、字号、描边、对齐全部调好；
2. 选中这些文本层（可多选）；
3. 再打开面板点「应用动画」。

面板不会改 `Source Text`，也不会动图层 `Position`，所以第 1 步的排版会完整保留。

### 2. 出现窗口 = 你给的段落框（点文本 = 文字外框）

窗口在应用时确定一次，站在文字原来的位置不动：

- **段落文本（框文本）**：窗口就是你画的**段落框**（宽高都不动）；
  **点文本**：窗口 = 文字自身范围 + 四边边距；
- 边距 **0 = 紧贴窗口**；正数向外扩（多留可见空间）；负数向内收（裁掉边缘）；
- 想把窗口做大：左右各加 100–300；想只显示文字所在的一小块：上下用负数收；
- 框是**层空间**矩形，图层缩放/旋转时框跟着文字一起变换；
- 框外文字完全不显示；**羽化只作用左右边缘**：横向滚动向框内扩散（超框完全看不到），
  逐字出现向框外扩散（框内全清晰）；
- 想让窗口随时间移动：目前参数是静态的；可以在应用后手动给 `DT_窗口` 蒙版路径打关键帧
  （重新应用会覆盖手改，注意顺序）。

### 3. 滚动方向与起止

- 滚动从**图层入点**开始，时长由面板「时长」决定；
- 起点：文字完全在文本框一侧之外；终点：完全到另一侧之外；
- 默认边距 0 时，文字行程 ≈ **2 倍文字宽**，不会再横穿整个画面；
- 想让它看起来只在原位置附近滑过：保持边距 0 即可；想留更多过渡空间就加正边距。

### 3½. 动态曲线怎么选

曲线只改**速度分布**，起止位置、时长、文本框都不变，默认两个都是「匀速」：

| 想要的效果 | 开头曲线 | 结束曲线 |
|---|---|---|
| 匀速（默认） | 匀速起步 | 匀速收尾 |
| 淡入淡出 | 慢起加速 | 减速慢收 |
| 前面快后面慢 | 快起减速 | 减速慢收 |
| 前面慢后面快 | 慢起加速 | 加速快收 |

- 「慢起加速」= 从静止慢慢起步；「快起减速」= 一上来就快；
- 「减速慢收」= 结尾缓缓停下；「加速快收」= 结尾加速离开；
- 两个下拉可以自由组合，端点严格对齐，不会跳变；
- 逐字出现时不使用方向/曲线/时长，整组「横向滚动参数」会隐藏（不是变灰）。

### 3¾. 逐字出现怎么调

一整套动画：窗口里从左往右逐字出现；打满后整行左移；
最后一个字出现后，整行用「隐藏(秒)」渐隐到 0，同时按「隐藏像素」向左移动。

- **窗口 = 段落框（框文本）/ 文字外框（点文本）**，不用另外填宽度；
- **出现(秒)**：整句所有字出现完的总时长（内部自动换算每个字的间隔）；
- **单字渐隐(秒)**：每个字自己的淡入时长；
- **隐藏(秒)**：最后一个字出现后，整行**不透明度 100% → 0%** 的用时（0.6–1.2 比较自然）；
- **隐藏像素**：同一段时间里向左走多远（默认 100）；0 = 原地渐隐；
  想让消失更有「滑走」感就调大（100–400 比较自然）；
- **羽化在框外（自动）**：逐字出现的窗口 = 段落框/文字外框，羽化向框外扩散，
  框内的字从出现那一刻起就是实的；文字不会右移，所以长句尾部的字也不会掉到框外；
- 零/正边距时出现阶段文字完全不动，每个字都在自己的位置上逐字出现；
  **想中途就左移，把右边距填负数**（例如 -200）；
- 会创建窗口蒙版，**框外文字不可见**；逐字出现的羽化向框外扩散（框内全清晰）；
- 左移量按**平均字宽**推算（文字宽 ÷ 字数），中英混排时节奏会有轻微差异；
- 图层出点会自动延长到「出现 + 隐藏」结束。

### 4. 逐字出现想更自然

- 默认「出现 2 秒 + 渐隐 0.12」比较稳：短句可以 1–1.5 秒，长句 3–4 秒；
- 想有「打字机」感：出现时间压短（1 秒内）+ 渐隐 0.03–0.08；
- 想有「逐字浮现」感：出现时间拉长 + 渐隐 0.2–0.4；
- 标点不单独做动画器；半角空格不建动画器，AE 26 实测在索引单位下也**不占索引** ——
  选区与节奏都按**非空白字符序号**（v0.11.11），所以不会错位；
  全角空格 / 制表 / 换行未真机验证，遇到时先看日志 `N 字(可见 M)` 与实际是否一致。

### 5. 生成后想微调

- **改某个字的出现时间**：展开文本层 → 文本 → 动画制作器 → `DT_渐隐NN` → 拖不透明度关键帧；
- **改滚动速度**：展开 `DT_滚动` → 位置 → 改表达式里的 `dur`（或在面板改「时长」后重新应用）；
- **改滚动速度分布**：面板选「开头曲线 / 结束曲线」后重新应用；
  也可展开 `DT_滚动` → 位置 → 表达式里改 `a / b` 两行（`a = k * k;` 等）；
- **改窗口**：直接改面板四个边距再点「应用动画」，不用手动改蒙版；
- **不要重命名** `DT_窗口` / `DT_滚动` / `DT_渐隐**` —— 清理按名称识别。

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 点「应用动画」没反应 | 时间轴里没有激活合成，或没有选中**文本层**（不是形状/纯色层） |
| 文字完全看不见 | 负边距把框收得比文字还小（至少保留 2px）；或强度接近 0 |
| 两端没有渐隐 | 羽化设成 0；或负边距把框收进文字内部，羽化落在文字上 |
| 逐字出现第一个字边缘发虚 | v0.11.5 起羽化向框外扩散，框内不羽化；若仍发虚，确认版本号是 `v0.11.11` 并重新应用 |
| 框外还能看到半透明文字 | 横向滚动 v0.5.1 起不应出现（羽化只向内）；逐字出现的羽化在框外（框内全清晰）；若看到请确认顶部版本号是 `v0.11.11` 并重新应用 |
| 点「应用动画」失败、提示 Error 对象 | v0.11.1 已修（整体渐隐与位移共用 DT_滚动）；确认版本号是 `v0.11.11` 并重开 AE |
| 应用后文字一开始就看不见 | v0.11.2 已修（渐隐关键帧改为 100 → 0，不再留全透明首帧）；确认版本号并重新应用 |
| 开头没有逐字出现、整行从 0 秒就可见 | v0.11.4 已修（整体渐隐不再挂在覆盖全行的 `DT_滚动` 上，改为写进每字动画器）；确认版本号是 `v0.11.11` 并重新应用 |
| **有两个字从 0 秒起一直显示 / 隐藏阶段也不消失** | v0.11.10 已修：每个动画器**逐个**切索引单位（`Units=Index`），再写 `ADBE Text Index Start/End = i / i+1`，精确只选一个字；百分比在字符数不能整除 100 时会把相邻字并进同一个选区。确认顶部版本号是 `v0.11.11` 并重新应用 |
| **空格后的第一个字从 0 秒起一直显示** | v0.11.11 已修：AE 26 真机**索引单位下半角空格不占索引**，而空格不建动画器 —— 按原文下标排会漏掉空格后第一个字的选区。现在索引与节奏都按**非空白字符序号**（`selIdx`）；日志显示 `N 字(可见 M)`。确认顶部版本号是 `v0.11.11`，先「移除动画」再重新应用 |
| 日志出现「设置选区失败…属性或父级属性被隐藏」 | v0.11.9 的索引切换写错了（只切第一个动画器 + 切完仍写百分比那对属性）；v0.11.10 已修。完全退出 AE 重开，确认版本号是 `v0.11.11`，先「移除动画」再重新应用 |
| 长句尾部的字没有逐字出现 | v0.11.5 修了羽化/右移；v0.11.6–v0.11.8 修了**段落文本溢出**（见下一行），确认版本号是 `v0.11.11` 并重新应用 |
| **出现时长(6 秒)像没生效、演到一半就停了** | 文本层是**段落文本（框文本）**，框高只够一行，后面的行被 AE 裁掉（框上只有溢出图标）—— 关键帧确实铺满 6 秒，但被裁的字一直不可见。v0.11.8 起：把排版框**单行化**（高保持一行，宽用「倍增 + 二分」加到能装下整行），再把**你给的原框（宽高都不动）当出现窗口**，文字在框内像终端一样从右往左流动；日志打印 `⚠ 段落文本溢出: 排版框 595x49 → Wx49px (官方 boxOverflow, 试探 N 次, 1 行), 改为单行; 你的框 595x49 作为出现窗口…`；没有溢出的层日志是 `段落框无溢出(全部文字都在框内), 框尺寸不改, 窗口=你的框`；若日志提示「源文本有动画」「仍排不成一行(可能含强制换行)」或「框高小于一行」则需手动处理 |
| **段落框宽度被加宽了(不是 bug)** | v0.11.8 要让长句不换行，AE 的排版框宽度必须够（框外文字不渲染，`boxText` 只读、脚本不能转点文本）。加宽的只是**排版框**，你的原框尺寸被原样存进蒙版名 `DT_窗口 595x49` 并当作出现窗口；文字只出现在原框范围内，重复应用也不会变 |
| 想回到原来的窄框 | 撤销一次（Ctrl+Z，整次应用是单 Undo 组）；或把段落框宽度手动改回你要的值，再应用会按新框当窗口 |
| 逐字出现打字时没左移 | 零/正边距时框宽≥文字宽，出现阶段本来就不推；把右边距填负数再应用 |
| 逐字出现结尾没滑走 | 「隐藏像素」太小：隐藏阶段本来就以渐隐为主，位移只是辅助；想滑走就调大到 200–400 看效果 |
| 上下边缘没有羽化 | 设计如此：羽化只作用左右边缘（上下羽化会把文字上下缘吃淡） |
| 框内文字整体变淡 | 「强度(%)」不是 100；它是蒙版不透明度，不是只影响边缘 |
| 面板上只看到一套参数 | 正常：方式选「横向滚动」只显示滚动参数，选「逐字出现」只显示逐字参数 |
| 重应用后出现两份动画 | 不应发生（按名称清理）；若手动改过动画器名，旧动画就清不到，需手动删 |
| 面板空白 / 按钮没反应 | 看桌面 `DialogueText_debug.log`，搜 `!!`；发整个日志最有用 |

### 面板打不开 / 空白时怎么排查

1. 先看桌面：`C:\Users\<你>\Desktop\DialogueText_debug.log`
   （桌面不可写时在系统临时目录，日志首行会写路径）。
2. 日志里搜 `!!`：UI 构建失败会带 `行号 / 文件 / 错误号 / 堆栈`；按钮异常也会记录。
3. 面板若还能显示兜底界面，直接点「复制日志」或「打开日志」。
4. 顶部版本号不是 `v0.11.11` → AE 没真正重启（面板只在启动时载入）。
5. 发给开发者时**整个日志文件**最有用，截图往往缺关键行。
