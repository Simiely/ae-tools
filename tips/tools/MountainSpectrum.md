# 山峰频谱 MountainSpectrum · 使用技巧

> 适用版本：AE 2026（26.0）中文版
> 相关插件：MountainSpectrum（`panels/MountainSpectrum/`）
> 创建：2026-09-18 · 更新：2026-09-18

## 认识产物：一个波峰 = 一组 3 个控制点

生成后时间轴里会多出这些东西，**它们就是你的操作台**：

```
山峰 柱            ← 形状图层。它的位置 = 行中心 X / 基线 Y。拖它移动整行
山峰 控制          ← 7 个滑块（排列参数 + 全局观感）
山峰点 1           ← 波峰 1 的「峰」
山峰点 1 左  /  1 右  ← 波峰 1 的左右边界
山峰点 2  ...
山峰 高度          ← 总闸：它离基线多高，整排最高柱就多高
```

> 所有高度 / 位置 / 半径都是**表达式驱动、不烘焙关键帧** —— 拖任何东西都实时生效，不用重跑脚本。

## 进阶用法

### 1. 做"一整排一起呼吸"的动效

给 `山峰 高度` 空对象的**位置 Y** 打关键帧即可 —— 它就是一个普通空对象。

形状完全不变，整座山等比升降。比逐个调点位快得多。

### 2. 做非对称波谱（attack / decay 不同）

音频波谱里，声音的**起音**往往比**衰减**陡。用左右边缘点就能做出来：

- 拖 `山峰点 k 左` 靠近峰 → 左边陡
- 拖 `山峰点 k 右` 远离峰 → 右边缓

**左右完全独立。** 反过来（左缓右陡）同理。

把某一侧边缘点拖到**峰的另一侧**，那一侧就整块消失了 —— 等于"只保留单边山丘"。

### 3. 独立控制某一根的宽度（低频宽、高频窄）

每个波峰有自己的左右边缘点 —— 对低频段把两个边缘点都拖远，高频段拖近，
就是"低频宽、高频窄"的真实频谱观感。

### 4. 在"叠加"和"取最高"之间选质感

| 叠加方式 | 效果 | 适合 |
|---|---|---|
| **叠加（求和）** | 多峰重叠处**相加**，会超过总闸高度 | 要让重叠区"顶起来"，形成连绵起伏 |
| **取最高** | 重叠处只取最高的那个峰 | 想让每个峰保持独立轮廓，互不干扰 |

> 叠加模式下，"总闸高度"约束的是**最高的那个峰**，不是全场最高的柱子 ——
> 两峰重叠处会比它更高。这是叠加的固有性质。

### 5. 用「边缘高度%」调范围边界的"硬"与"软"

`柱高 = 基础高度 + (峰高 − 基础高度) × 衰减` —— 衰减作用在**地板之上**，
所以只要这个值 > 0，**范围内每一根都保证高于基础高度**（都看得见）。

| 值 | 手感 |
|---|---|
| **100%** | 范围内全平 —— 像频谱条，根数最准、边缘硬切 |
| **10%（默认）** | 边缘比地板高一截，山形柔和 |
| **0%** | 边缘落回地板（看不见），但**范围边界完全无台阶** |

> ⚠️ 范围边界天然有一道台阶（范围内最低比范围外高 `可用高度 × 边缘高度%`）。
> **这个参数就是台阶的旋钮**：调小台阶变轻，调到 0 台阶消失但边缘也看不见了。

### 6. 预设与跨工程复用

- 4 个槽位存在**工程所在目录**的 `MountainSpectrum.presets.json` —— 跟随工程走
- **存储前必须先保存工程**（Ctrl+S），没保存状态栏会提示
- 想让一套参数跨工程用 → 点「导出配置」，下次在新工程里点「导入配置」
- 导出 / 导入的对话框都会**默认打开工程所在文件夹**
- 「使用」只回填面板，**不会自动生成**（避免误毁当前合成）；回填后要点「生成 / 重建」

### 7. 整块搬走图样而峰形不变

点位是**世界坐标**，行是从点位下面"滑过"的。所以：

- 只拖 `山峰 柱` → 峰形会跟着变（柱子走到不同点位下面，高度重算）
- **把 `山峰 柱` 和所有 `山峰点`（含左右边缘点）一起选中再拖** → 整块搬走，峰形不变

### 8. 快速铺满合成宽度

勾选「自动铺满合成宽度」，填一个「矩形宽」和「间距」，数量自动算 ——
适合快速看效果。定稿后再取消勾选、手动指定数量。

## 踩坑记录

**Q：改「数量」之后形状没变 / 变了但不对？**
「数量」和「点数」是**生成时写死**进表达式的，必须点「生成 / 重建」。
其余参数（宽 / 间距 / 曲线 / 叠加 / 倍率 / 边缘高度 / 基础高度）都是实时。

**Q：拖「山峰点 k 左 / 右」完全没反应？**
这两个图层和读写它们的表达式都是**生成时建**的 —— 旧工程（在本功能出现之前生成的）
需要点一次「生成 / 重建」。

**Q：生成后一片空白，什么都没有？**
先看时间轴里有没有 `山峰 柱`。若有图层但看不到柱子，检查「基础高度」是不是已经超过峰高
（那会把整排压成一片平高原）。把「基础高度」调小即可。

**Q：范围边缘那几根矮得看不出来？**
把「边缘高度%」调大。若基础高度很高、峰高很小，可同时把「点位高度」或总闸拉高。

**Q：范围边界有一道明显的台阶，很突兀？**
把「边缘高度%」调小（0% 完全无台阶）。**这是"圈定范围"的代价**，不是 bug ——
想让范围内外有区别，边界处就必然有落差。

**Q：面板上改「点位高度 / 边缘高度%」没生效？**
这两个字段改完**会实时推给图层**。但老工程里可能还没有对应的滑块 ——
点一次「生成 / 重建」就会补上。

**Q：拖「山峰 高度」整排一起压平了？**
你把它拖到基线或以下了。拖回去即可。**删掉这一层 = 关闭总闸**，回到各点位独立高度。

**Q：想临时关掉"总闸"但不想删图层？**
没有开关 —— 删掉 `山峰 高度` 这一层就是关闭方式（表达式会自动回退到各点位独立高度）。

**Q：点位「影响范围」填 9，实际影响了几根？**
正常情况下**恰好 9 根**。唯一例外：行根数为偶数、且点位正好落在两根柱子正中时，
会得到 10 根（对称窗口左右等距，无法二选一 —— 几何事实）。
