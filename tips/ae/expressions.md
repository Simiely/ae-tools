## 常用套路

### 数字计数器（滑块控制）

**场景**：数字整数递增，可控制速度与暂停时机（评分、数据条数字等）。

**设置**：
1. 文本图层加两个「滑块控制」，分别命名「起始值」「速度」
2. 「速度」滑块打关键帧：`0` = 暂停，正数 = 每秒增量
3. 源文本粘贴表达式

```javascript
startVal = effect(1)("滑块");   // 第 1 个滑块 = 起始值
spd = effect(2)("滑块");        // 第 2 个滑块 = 速度

t = 0;
v = 0;
while (t < time) {
  v += spd.valueAtTime(t) * thisComp.frameDuration;
  t += thisComp.frameDuration;
}
Math.round(startVal + v);
```

> 按效果序号（`effect(1)`/`effect(2)`）引用不依赖效果名，改名不影响；图层还有其他效果时按实际位置调整序号。

**控制**：起始值拖滑块；速度调滑块值；暂停/继续在时间轴给「速度」打关键帧（`0` = 暂停）。

> 逐帧累加，普通短视频流畅；超长合成拖时间轴可能略卡。

## 注意事项

- ExtendScript 表达式引擎为 ES3，无 const/let/箭头函数（详见 knowledge-base 速查表）
