# 面板模板 PanelTemplate — 变更记录

> ⚠️ 派生新面板时，把本文件的「面板模板」改成你的面板名，保留版本号格式
> （`## vX.Y.Z` 必须顶格，`verify.py` 与测试都会读它来校验版本一致性）。

## v0.1.0 (2026-09-21) —— 模板初版

从 MountainSpectrum v1.5.6（仓库里唯一完成度最高的面板）提炼通用骨架，**只抽通用的部分，
不抽它的业务**。承载的每一条约定都有真实出处：

- **顶部常驻版本号 + `VER` 常量**：AE 只在**启动时**载入 ScriptUI Panel 脚本 ——
  改完不重启 AE，面板里跑的还是旧版，且 AE 报的错可能是**旧文件**的行号
  （2026-09-21 实测：AE 比脚本早启动 33 分钟，报的「行 2069」属于旧文件）。没版本号就无从判断。
- **测试导出闸门**（`if (typeof app === "undefined")`）：位置有硬约束 ——
  纯函数定义之后、AE 代码之前，末尾必须 `return`。有了它，纯逻辑层才能在 node 里跑断言。
- **`safeRun` 包裹所有 handler**：AE 的 ScriptUI handler 抛错**完全静默**，
  这就是「点击没反应」的根源。
- **`pinW` 三处都写**（`preferredSize` / `minimumSize` / `maximumSize`）：
  `preferredSize` 是 volatile 属性，首次布局即丢失，只写它会失效。
- **`fixedBox` 先钉宽度再钉高度**：`pinW` 内部把 `preferredSize` 重置为 `[w, -1]`，
  顺序反了会被**静默覆盖**（此坑在本仓库潜伏了 4 个版本：调试区设的 110px 一直没生效）。
- **`scrollable` 存在性回退**：本仓库有先例（`colorpicker` 在 AE 宿主里直接报 unknown）。
- **单 Undo 组 + `finally` 收尾**、**「未激活合成」状态栏 + 弹窗双提示**、**诊断三件套**。

测试 45 条断言，含 6 组**骨架体检断言**（守住上面这些约定本身）——
两类断言都做过反向对照（故意改坏源码 → 必须变红）。
