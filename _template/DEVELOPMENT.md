## 继承自模板的坑（不是本面板踩的，是骨架已经替你挡掉的）

这些坑都来自 MountainSpectrum 的真实事故。骨架里的写法看着冗余，**每一条都对应下面一次事故** ——
`test_PanelTemplate.js` 的第六组断言专门守着它们，删掉会直接变红。

### 坑 A：AE 报「在行 N 无法执行脚本」，而那一行是干净代码

**现象**：AE 弹「在行 2069 无法执行脚本。应为:」，同一症状在早期版本报的是「行 1871」。

**根因**：**AE 没重启**。ScriptUI Panel 由 AE **启动时**载入；磁盘文件后来被覆盖，内存里仍是旧版，
于是它报的是**旧文件**的行号，与磁盘上的代码无关（实测：AE 比脚本早启动 33 分钟）。

**修法**：① 先证伪"当前文件有 bug"（`node --check` + Rhino 编译 + 不可见字符扫描）
② 比对 **AE 进程启动时间 vs 脚本 mtime**，前者更早就是没重启
③ **把版本号做进面板 UI** —— 打开面板即可判断 AE 里跑的是哪一版
④ 让用户**完全退出 AE** 再开（关面板 / 关工程都无效）

### 坑 B：给控件设了 `preferredSize` 高度却不生效

**现象**：「调试输出区」明明写了 `preferredSize = [320, 110]`，内容一多面板照样被撑高 ——
这个 `110` 形同虚设，潜伏了 4 个版本才被发现。

**根因**：紧随其后的 `pinW()` 内部有 `ctrl.preferredSize = [w, -1]`（**-1 = 高度自适应**）——
**在它之前设的高度被静默覆盖**。没有任何报错，只是"看起来没生效"。

**修法**：**先 `pinW` 钉宽度，再单独钉高度**（模板里抽成了 `fixedBox`）。

**验证**：源码级**顺序体检**断言 —— `pinW` 的位置下标必须小于 `box.preferredSize = [w, h]`，
并做反向对照（两条对调立刻变红）。

> **通用做法：`pinW` 之后再设高度。顺序反了不会报错，只会"看起来没生效"。**

### 坑 C：`pinW` 只写 `preferredSize` 不够

**现象**：控件宽度钉了又被改回来，面板"弹宽"。

**根因**：`preferredSize` 是 ScriptUI 的 **volatile 属性，首次布局即丢失**
（Adobe 官方社区 Marc Autret 采纳答案：需要改用 `minimumSize`）。

**修法**：`preferredSize` / `minimumSize` / `maximumSize` **三处都写**。

### 坑 D：同一套数学写两遍（纯函数 vs 表达式）会分叉

**现象**：`ftype` 取非法枚举值（如 9）时，**画面按二次曲线渲染，状态栏的可见根数却按余弦算**
—— 数字和画面对不上（实测 40 根里 8 根不一致）。

**根因**：纯函数用 `=== 1/2/3` 精确匹配（越界落默认分支），表达式用 `< 1.5 / < 2.5` 阈值分段
（越界落 `else`）。**两份实现同一套数学，边界上必然分叉。**

**修法**：两侧统一「先 `Math.round` 再夹到合法范围，越界回退默认值」，表达式侧内联同一规则。

**验证**：**边界等价性断言** —— 把边界用例固化成"纯函数 vs 表达式逐值比对"，
不只测正常区间。审计发现时就是靠 25 个边界用例 × 40 根 = 1000 次比对抓到的。

> **通用做法：任何"纯函数 + 表达式手工镜像"都要有边界逐值比对；只测正常区间等于没测。**

### 坑 E：`scrollable` 这类控件属性在 AE 宿主里可能不被支持

**现象**：`colorpicker` 在 ScriptUI **Panels** 宿主里直接报
`UI element type ... is unknown or invalid in this context`。

**修法**：对"较新/较冷门"的控件属性做**存在性回退**（`try` 新建带属性的、失败了退化成基础形态），
**绝不让面板整个打不开**。模板里 `fixedBox` 的 `scrollable` 就是这么处理的。

### 坑 F：AE 的 handler 抛错是静默的

**现象**：点按钮什么也没发生 —— 没有报错、没有日志。

**根因**：ScriptUI handler 里的异常不会冒泡到任何可见的地方。

**修法**：所有 handler 经 `safeRun()` 包裹 + 诊断三件套（`diag` 收集 / 调试区显示 / 复制按钮）。
**这是"坏了一定查得到"的底线。**
